# BobTV 地区目录同步

账号受保护接口已接入 Flutter 频道页、地区选择和同步调度。生产环境已部署新接口与独立签名密钥。旧匿名目录入口仍保留，待新客户端迁移及实机验收完成后切换。

## 已接入的客户端行为

- 游客安装开放授权直播范例；账号地区目录按账号隔离。主界面账号入口旁可选择地区。
- 同步沿用现有目录的频道、线路及 EPG 标识。完成验签后才调用现有目录导入事务。
- 启动、回到前台及五分钟定时刷新合并重复请求；下载失败保留上次有效目录。地区订阅保存在本机账号缓存中。
- 退出或换号先归档原账号的收藏及关联记录，再移除其受保护目录和活动视图；个人导入源保留。失效登录不能恢复受保护频道。
- 过期的异步响应在修改本机目录前重新核对账号，防止退出后回写旧目录。
- 三个演示频道的生产地址为 `/api/v1/demo/`，独立服务提供持续更新的 HLS、节目单及授权说明；视频范例是开放动画素材轮播和实时生成的测试信号。

## 数据包和认证

- GET /api/v1/regional-catalog/bootstrap.bobtv 是可公开下载的引导包，只有协议版本、BobTV API 地址、目录签名公钥与指纹，不包含生产线路。私有资源包 v1 保持原状。
- 客户端先在现有账号主站通过 HTTPS 读取真实公钥，再核对导入包的 API 地址和指纹。文件中的公钥不能单独承担信任。匿名引导请求不带登录令牌。
- 客户端为每个账号在本设备安全存储中生成独立 Ed25519 私钥，服务端只登记公钥。首次登记需要经过验证的账号、十分钟内登录和一次性签名。后续同步同时需要有效会话和已登记设备的签名。签名覆盖用途、账号、设备、地区和已有版本，挑战在九十秒后失效，不能重放或转用其他登录会话。
- 地区列表只返回代码与台数。同步每次只返回一个地区，签名响应携带 API 地址、公钥、地区及内容版本。版本相同只返回回执。香港、澳门、台湾各自归组。没有可信地区归属的频道暂不放进地区包。
- 服务端签名用独立密钥，配置为 BOBTV_REGIONAL_CATALOG_SIGNING_KEY 所指向的 32 字节 Ed25519 私钥文件，仅签名服务可读。账号设备私钥、服务端签名私钥均不得进入数据包、日志或客户端渠道。

## 切换顺序

1. 接入地区选择及按账号保存的订阅列表。先验签再原子入库，保留现有公开频道及线路 ID，不经过个人包的 ID 重命名流程。
2. 按所选地区检查版本，启动、恢复网络和前台时合并重复请求，后台低并发刷新。下载或校验失败时保留上次有效缓存。地区 EPG 通过原有精确线路映射按需取用，切换不重新打开正在播放的视频。
3. 在主界面启用游客仅 DEMO，按账号隔离本机地区缓存、收藏入口及搜索结果。明确退出和切换账号时清理内存视图，不删除个人导入源或收藏数据。补齐设备解绑和目录签名公钥轮换流程。
4. 新版迁移成功后再关闭旧匿名公共目录、全量 EPG 与其它能列出同一批正式资源的匿名镜像路径。切换前，新接口的鉴权只保护新接口，旧公开地址仍可访问。关停前核对旧客户端影响、签名和镜像行为。

## 发版验收边界

隔离测试已覆盖签名协议、精确标识、失败保留缓存、收藏恢复、注销保留个人源和异步响应隔离。正式验收仍需包含实际 BobTV 文件导入、登录、地区切换、后台刷新、注销及换号隔离，并在支持的各端验证安全存储和播放器行为。设备解绑及签名公钥轮换需要单独核验；不能由协议单元测试推定已完成实机验收。

游客范例的官网及镜像播放列表更新、视频分片检查已有生产验证。Google 和 Apple 登录取决于对应开发者应用配置，SMTP 配置独立管理。账号配置、设备私钥和服务端私钥只放在受保护的配置存储中。
