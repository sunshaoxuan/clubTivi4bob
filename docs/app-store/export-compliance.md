# 加密出口申报工作表

不能依据“仅是播放器”就直接回答“不使用加密”。

当前观察到：HTTPS、系统钥匙串、账号凭据、Dart SHA-256/HMAC 相关用途，以及原生媒体依赖中的 MbedTLS/Mbedcrypto/Mbedx509。尚未合并的地区目录代码另使用 Ed25519；是否进入正式二进制须在冻结构建中核实，不能仅凭 pubspec 出现依赖就判定已使用。

没有在源 Info.plist 中找到 `ITSAppUsesNonExemptEncryption`。本次准备不写入未经确认的布尔值。

正式提交时，根据最终包中算法实现方、用途、发行国家和 App Store Connect 问卷确定是否豁免、是否需要附件及是否涉及法国申报。系统加密的常见豁免不能直接覆盖嵌入式第三方加密实现。由账号持有人确认最终答复；本材料不伪造 CCATS、政府许可或豁免证明。
