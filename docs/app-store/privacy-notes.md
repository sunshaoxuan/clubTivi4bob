# 隐私申报草稿

本材料不提供已签署的“无数据收集”声明。账号、可选诊断及部分网络服务都需在最终申报中体现。

`privacy-data-map.csv` 将已观察到的数据、候选 Apple 分类及待确认条件逐条列出。用户可选择不同意诊断，但数据可选并不自动免除披露。稳定安装 UUID 与诊断内容可能关联设备，不能仅因它不是姓名就填写“不关联用户”。

已观察到的 iOS 私有来源模式会跳过公共目录同步和设备收藏云备份。不要直接把桌面版的所有数据活动复制为 iOS 实际活动，也不能推定 iOS 所有网络活动均不经过服务器。应记录首次启动、导入、播放、台标、节目指南、字幕、注册、删除和诊断开关的实际请求。

`technical/bundled-privacy-manifests.json` 为现有模拟器包的 SDK 清单，不等于最终设备 Archive 的 Xcode 隐私报告。根目录的示例隐私清单包含故意留空的数据采集项，只供后续实现参考，不能原样作为正式“未收集任何数据”的申报。

最终应在 Xcode Archive 中生成隐私报告，核对自有代码和原生媒体库的文件时间、磁盘、系统启动时间及偏好存储 API，再填写与实际用途匹配的允许理由。不能只凭存在 SDK manifest 就认定整个应用完成申报。

公开隐私 URL： https://bobtv.briconbric.com/privacy 。须再次确认其内容与提交版本的数据用途、处理方、保留、删除和联系方式一致。
