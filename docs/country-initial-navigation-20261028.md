# 国家选择首字母快速导航

## 目标与范围

用户指出国家或地区菜单数量多、逐个寻找困难，要求按首字母归类并快速导航。基于当前 origin/main `6e7e143` 的实际 CompactCategoryRow 菜单，实现国家专用首字母导航与名称搜索，保留选中状态、点击选择和右键/长按置顶。旧分类及 Mac 调查保持独立，本次不部署服务或发布安装包。

## 本批实现与方法

1. 核对已有 CountryNames 规范化和依赖，中文名称按拼音首字母，拉丁名称按首字母，不修改国家身份或目录数据。
2. 保持其他分类菜单行为。复用成熟 Flutter 控件，采用有界的国家菜单增补，不新增通用导航框架。
3. 主 Agent 落地实现；只读 Agent 复核国家索引规则和测试边界。三个文件内的局部 UI 与有限国家索引增补由主 Agent 直接实现。可见变化由真实运行截图、浏览器功能与 Gemini 视觉复核共同验证。
4. 先执行必要针对性行为测试及廉价前检，冻结候选后合并执行项目要求的检查。相同输入有效结果直接复用；新增相关改动才重跑受影响范围。

## 交互与视觉预算

目标视口 1280×800、390×844，并覆盖320px最窄内容及长国家名、放大字体。沿用菜单深色边框与选中样式，标题/关闭、搜索、首字母、国家列表由上到下形成共同栅格。浮层四周至少12px安全边距。搜索与主要点击热区至少44px高，组内相邻热区至少6px。字形距离背景内框四边至少3px，垂直视觉中心误差不超过 min(2px,字形高度10%)。必要特殊预算须在实现前补充，不在验收时放宽。

## 逐项验收

- 中文、英文、别名、空列表、特殊字符和全部国家条目索引正确，分类身份及回调保留。
- 点击首字母显著缩小查找范围或跳转至对应分组，搜索、清除、无结果和重新打开状态正确。
- 当前选中项保持可辨，长名称可读，国家置顶操作保留，其他分类菜单回归通过。
- 桌面与窄屏真实运行功能、控制台、资源请求、截图及原尺寸局部验证；每个变更控件的字形、可用内框及热区记录。
- 冻结候选后执行受影响测试并报告项目检查实际结果；更新说明、证据和发布评估随代码提交。缺少必要运行证据时保持未完成。

## 进展

已确认旧工作区落后于截图版本；独立工作区从最新 main 建立，原工作区七个插件生成文件改动保持原样。现有菜单采用 Wrap 滚动列表，没有国家首字母和名称搜索。

国家菜单采用标准 Dialog，最大480×620，随窗口与软键盘可用区域收缩；空间紧张时字母栏横向滚动。国家名称按实际显示文字索引，秘鲁按 B，无法索引的名称进入 #。已有 CountryNames 规范名与别名目标的有限字首表通过覆盖检查约束，避免新增通用拼音运行依赖。搜索支持名称、现有英文别名、国家代码及单个首字母。

只读复核和针对性测试指出短窗口加键盘需要整体滚动、放大字体的“全部”需要自然宽度，两项已修正。实际浏览器首轮截图发现桌面主题密度将44px的 minimumSize 缩成36px，因此该轮几何验收 FAIL；国家菜单按钮显式使用标准密度，搜索框最小48px，新增紧凑主题回归。预设验收预算保持原值。最终截图需来自该修正后的构建。

首次针对性测试发现测试夹具把 GB/UK 相同名称生成了重复 ID，以及测量对象落在 Dialog 的全屏外层。已按生产中的唯一国家 ID 修正夹具，并将测量键放到实际菜单表面；原有普通分类菜单回归已经通过。下一轮检查覆盖这些修正及短窗口大字体。

## 最终候选与验收

正式全量后新增的只读复核发现焦点生命周期缺口。先补320×420、输入后切换180px键盘 inset 的反例，实际在 hasFocus 断言处失败。此发现使上一候选的“键盘连续输入”和整体验收失效，原870通过结果保留为上一候选记录。最小修复为使用稳定 GlobalKey 保留搜索编辑子树；新增测试同时检查键盘弹出/收起、选区和连续输入。该变化不改变布局或样式。修复后先重测该回归，再冻结新候选统一重跑正式 Flutter 检查，刷新组件宿主及运行证据；这是本轮额外全量的相关失效输入与范围。

浏览器补验进一步发现 GlobalKey 只保留 Flutter 编辑状态，Web 输入层仍因祖先重挂失焦；同模式320×240→320×260对照保留焦点，证实问题来自模式切换。最终实现固定 Scrollbar/SingleChildScrollView/SizedBox/Column 的父级结构，仅改变可用高度和滚动方式，移除 GlobalKey 中间方案。全部12项菜单回归通过后，先实测浏览器跨模式连续输入，再冻结正式候选。第二候选871通过结果保留在 before-web-focus-fix 身份记录；其键盘Web验收已失效。额外全量仅针对这次已复现的相关修复。
