# 收藏取消与勾选修复

## 问题与修复

已复现取消收藏和后台补齐成员并发时，旧成员快照把已删除收藏写回的问题。
回归用例修复前得到 `{'a','b'}`，修复后为空集合。`v1.1.12` 中也保留了这段
未使用事务的补齐与删除逻辑。新增、删除及补齐操作现使用事务，取消时也清除
同一保守频道身份下的已屏蔽旧成员，保留频道、线路、分类和 EPG 映射。

星标及菜单的主操作现直接切换收藏，取消操作支持撤销。多收藏夹逐项分配使用
独立的“管理收藏夹”入口。打开空选项管理界面不会重新收藏。Windows、macOS
和 Android 共用弹窗组件，勾选立即更新，写入串行进行，保存失败回滚并显示错误，
关闭弹窗后仍完成已排队写入。大量收藏夹在受限高度内滚动显示。
