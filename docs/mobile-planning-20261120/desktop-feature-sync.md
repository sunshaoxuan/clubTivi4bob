# 桌面功能同步与移动验收

日期：2026-11-20，日本时间。本轮属于本地开发与官方模拟器验证，没有发布或部署。

## 共享基线

初始移动分支为 1.1.21。先提交已验收的手机抽屉和平板方向布局为 `2fbd8a3`，再获取并合入桌面远端主线 `d939ed0`，形成合并提交 `eb4a093`。共享版本随主线为 1.3.1+1。合入范围包含字幕语言及版本选择、节目单实际线路绑定、HLS 缓冲与字幕恢复等既有桌面实现。

合并时同时保留手机播放状态订阅、节目单线路订阅，以及两种既有测试静音开关。保留 iPad/Android Pad 竖屏上下、横屏左右的规则，手机维持频道抽屉。

## 功能接入

| 功能 | 手机和平板处理 |
| --- | --- |
| 收藏 | 手机频道卡片可直接收藏；当前节目有快捷入口；复用桌面收藏与收藏夹数据，保留原有撤销行为 |
| 收藏夹 | 更多菜单可打开当前频道所属收藏夹与全局收藏夹管理，复用创建、重命名和删除界面 |
| 最近播放 | 手机最近频道 ID 保存到本地，最多 50 个；列表仍遵循当前分类和来源筛选 |
| 节目单 | 当前及后续节目展示，触控面板可查看最多 20 项；按实际播放线路解析 EPG，并应用时间偏移 |
| 字幕 | 接入共享字幕菜单，包含七种语言、关闭、跟随界面语言、版本选择及重试。iOS 离线语音识别运行时尚未打包，不能视为外部字幕自动对齐已完成 |
| 全屏 | 触控控制条提供返回、播放暂停、静音、字幕、收藏和更多。更多包含音轨、截图、播放信息、名称、投屏、频道和返回。单音轨时禁用音轨切换；iOS 不显示尚未实现的系统 PiP |
| 全屏频道 | 竖屏底部抽屉，横屏右侧抽屉，视频保持挂载。系统返回先关闭频道抽屉 |
| 线路与分类 | 通过触控菜单进入既有线路管理、频道分类等操作，弹出菜单按实际窗口限宽限高 |
| 截图 | 复用原生帧截图，移动端先预览，再由系统文件选择器导出；不向用户显示临时目录 |
| 来源与设置 | 手机和平板更多菜单统一提供播放源、线路检查刷新、界面语言和设置入口 |
| 七语言 | 补齐本轮新增手机与触控菜单文案 |

修正全屏旧信息栏在手机上的溢出，复用能自动换行的节目文字组件，控制条遵循安全区域。频道列表使用 Material 承托点击反馈。全屏切台后返回主页，或者返回后异步切台才完成，界面按实际播放器频道身份更新标题、节目单和选中项。

## 能力边界

- iOS 的离线 ASR、系统 AirPlay 和系统 PiP 仍需原生实现与真机验证。本轮没有下载可执行资源包替代原生实现。
- 多音轨切换、真实电视投屏、系统文件导出最终落盘及全部线路管理写操作尚未逐一设备验收。已验证截图预览，不将系统导出按钮存在视为导出已通过。
- 测试没有执行频道合并、线路转移、淘汰或公共分类修改，没有部署合入的服务端与网站代码。
- iPad 多任务窗口拒绝程序设置方向，本轮保持竖屏；物理旋转与多任务布局仍需独立验收。
- 模拟器验证不能替代音视频同步、长时间播放、后台恢复、耗电及商店验收。
