# BobTV 1.0.0

Application version: `1.0.0+81`.

## Installation packages

* Windows x64: Setup installer with administrator authorization, default installation to `C:\Program Files\BoB\BoBTV`, Start menu entry, optional desktop shortcut and uninstaller. The desktop shortcut choice remains respected on subsequent starts. Per-user channel data and favorites are preserved during uninstall.
* Windows x64: ZIP portable package remains available for writable per-user installations and automatic updates.
* macOS Intel and Apple Silicon: DMG with drag-to-Applications installation layout, plus publisher-signed ZIP update payloads. Apple Developer ID signing and notarization are not available for this release.

## Changes

* Return from fullscreen playback goes back to the channel browser while preserving application fullscreen state. A single Return to channels control replaces duplicate top controls.
* Unify fullscreen exit paths and preserve window bounds through native transitions.
* Support Unicode component paths on Windows.
* Preserve shared public channel initialization, asynchronous classification and route-health synchronization, idempotent route deduplication, and persistent retirement.
* Align application, package and update-feed version numbers.

## Update permissions

Windows Setup installations check for new versions and explain that upgrades require downloading and running the newer Setup with administrator authorization. They do not start an unprivileged automatic installer against Program Files. Portable Windows installations and macOS applications in writable locations retain background downloads, visible progress, verification, installation on exit and backup/rollback mechanisms. A protected macOS installation requires manual replacement.

Downloads: https://bobtv.briconbric.com/downloads

Third-party stream availability and content identity cannot be guaranteed. No installed desktop application is restarted during release publication. GitHub Actions remains disabled; packages are assembled manually.
