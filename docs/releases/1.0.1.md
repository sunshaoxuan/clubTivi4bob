# BobTV 1.0.1

Application version: `1.0.1+82`.

## Fullscreen and exit controls

* Windows fullscreen now provides an edge-reveal window toolbar across the player, channel browser and other application pages. Move the mouse to the top edge to reveal Minimize, Restore window and Close BobTV. The toolbar hides when the mouse leaves it.
* Preserve the normal Windows titlebar style during entry into native fullscreen. Restoring a window returns its native controls.
* Add a separate Exit button to the simple browser, advanced browser and fullscreen player controls. Return to channels continues to preserve application fullscreen and does not exit the application.
* Keep macOS native fullscreen titlebar behavior unchanged.
* Closing uses the normal native window-close path, allowing independent update workers to complete.

## Packages and updates

Windows x64 Setup, Windows portable ZIP, Intel Mac DMG and Apple Silicon Mac DMG are available. Windows Setup defaults to `C:\Program Files\BoB\BoBTV` and supports an optional desktop shortcut.

Windows Setup installations require administrator-authorized Setup upgrades. Portable Windows applications and macOS applications in writable locations retain automatic updates, visible progress, verification and backup/rollback behavior. Apple Developer ID signing and notarization are unavailable for these Mac packages; macOS may require manual approval to open them.

Downloads: https://bobtv.briconbric.com/downloads

Public channel synchronization remains enabled. Third-party stream availability and identity cannot be guaranteed. GitHub Actions remains disabled; packages are built manually. Existing installed applications are not restarted during publication.
