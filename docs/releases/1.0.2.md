# BobTV 1.0.2 (build 83)

## Update-check feedback

- Update checks show an immediate spinner in settings and the desktop status badge.
- Results distinguish an up-to-date installation, connection failure, a skipped unhealthy version, and an installation requiring administrator authorization.
- Returning to the foreground checks the BobTV HTTPS feed when at least 15 minutes have elapsed since the previous foreground check. Startup and six-hour checks remain enabled.
- A new check cannot replace the progress of an active download, verification, ready package, backup, or installation.
- The settings page displays the live result instead of a generic completion message.

## Existing desktop controls

The 1.0.1 mouse-operated exit controls and Windows fullscreen top-edge window controls are retained. Returning to channels preserves the fullscreen window. macOS keeps its native window controls.

## Platform availability

This publication includes Intel and Apple Silicon macOS DMGs and publisher-signed update ZIPs. Windows source contains the same update-check changes; its build host is powered off, so the Windows 1.0.2 installer and ZIP are pending. Windows downloads and the automatic-update feed remain at the verified 1.0.1 build 82. The download page labels each platform's actual latest available version.

Windows Setup installations require administrator-authorized Setup upgrades. Per-user Windows portable installations and writable macOS installations use the existing background download and post-exit installer. No protected installation directory permissions have been weakened.

macOS packages use ad-hoc application signing and the BobTV update publisher signature. Apple Developer ID signing and notarization are not available. ARM packages are cross-built and validated structurally; this Intel build host cannot perform an ARM runtime test. No running user application is restarted during publication.
