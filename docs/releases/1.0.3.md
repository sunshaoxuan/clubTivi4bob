# BobTV 1.0.3 (build 87)

## Desktop picture-in-picture

- Windows and macOS support a floating, always-on-top desktop player.
- Playback uses the existing player and decoder. The small window supports dragging, resizing, volume, mute, return to channels, and exit.
- Returning to channels preserves the current programme and the fullscreen window state.

## Fullscreen programme guide

- The top overlay places the channel name on the left, programme information in the center, and return/exit buttons on the right.
- A lightweight text guide displays the current programme, its start/end time, and the next two programmes with their times.
- Missing programme entries are explicitly labelled. EPG queries use the channel's exact identifier and configured time shift.
- Moving the mouse reveals the overlay; idle controls and pointer hide automatically.

## Windows update reliability

- Update installation pauses the application-scoped crash monitor and verifies copied files. Unchanged locked helper files do not need replacement.
- The launch button remains disabled through download, verification, backup, installation, and failure. It becomes available only after the installed executable matches the completed version.
- Existing catalogue synchronization, mouse-accessible exit controls, and Unicode installation-path support are retained.

## Packages and validation

Windows x64 Setup and portable ZIP, Intel macOS DMG/update ZIP, and Apple Silicon macOS DMG/update ZIP are included. Public downloads and platform-specific update feeds are mirrored at https://bobtv.briconbric.com.

Windows playback, desktop PiP, return to channels, and fullscreen EPG were confirmed on the test host. Automated tests cover fullscreen/PiP state, guide layouts, update progress, helper locks, rollback, and catalogue synchronization. The final packages are checked for archive structure, checksums, and Mac publisher signatures.

macOS applications use ad-hoc signing and BobTV publisher-signed update archives. Apple Developer ID signing and notarization are unavailable. Apple Silicon packages are cross-built and structurally validated; native ARM runtime testing is not available on this Intel build host. Multi-monitor and long-duration playback checks remain separate from these release validations.

Windows Program Files installations require administrator-authorized Setup upgrades. Writable per-user Windows and macOS installations support background download and post-exit installation. No protected directory permissions are weakened.
