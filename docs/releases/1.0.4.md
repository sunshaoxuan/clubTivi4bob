# BobTV 1.0.4 (build 89)

## A redesigned settings workspace

Windows and macOS share a new settings interface aligned with the simplified
channel browser: navy surfaces, pale-blue selection, rounded panels, and clear
spacing. Seven categories organize channels and guides, playback, display and
remote control, synchronization and privacy, AI and media services, recording
and backups, and updates and application information.

Wide windows use a sidebar. Narrow windows use scrollable category tabs; key
action buttons wrap instead of overflowing. Categories load on first visit and
retain unfinished forms and scroll positions. Hidden forms cannot receive focus
and their animations are paused.

Existing preferences, credentials, playlist and EPG management, recording,
backups, public catalog synchronization, consent controls, and update operations
are retained. AI, XMLTV and Debrid detail screens and settings dialogs use the
same visual style. Entering a media-service key immediately enables saving.

## Reliability

Web remote teardown no longer sends client-count events into a closed stream.
Stopping the remote server safely iterates over a snapshot of connected clients.

The public catalog tools remain BobTV extensions. The manual release browser
downloads and verifies packages; automatic update status is a separate entry.
Feedback and automatic diagnostic-summary uploads remain off by default.

## Downloads and validation

This release includes Windows x64 Setup and portable ZIP, Intel macOS DMG and
update ZIP, and Apple Silicon macOS DMG and update ZIP. Downloads and all three
platform update feeds are mirrored at https://bobtv.briconbric.com.

The shared settings/player/update regression suite passed 54 tests, with one
optional visual fixture skipped. Windows settings/update tests passed 21 tests.
Installer fixtures covered Chinese/Japanese paths, both desktop-shortcut choices,
start-menu shortcuts and uninstall. Both installed test-host applications were
started; Windows reported video output and startup health. The installed Intel
Mac Metal adapter passed 500 callbacks and 4000 two-stream frames, resize and GPU
readback without retained backings. Package structures, SHA-256 values and Mac
publisher signatures were verified.

macOS packages use ad-hoc application signing and BobTV-signed update archives.
Apple Developer ID signing and notarization are unavailable. Apple Silicon is
cross-built and structurally validated; native ARM runtime testing was unavailable
on the Intel build host. Native settings appearance and live audio quality are
separate from automated validation. Windows retains a pre-existing unsupported
`loudnorm` filter warning; video output continued during the test.

Protected Program Files installations require administrator-authorized Setup
upgrades. Writable per-user Windows and macOS installations retain background
download and installation after exit, with previous-version backups.
