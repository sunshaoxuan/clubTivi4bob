Validation date: 2026-10-12 (Japan local time).

## Automated acceptance

- Flutter: 375 passing tests and 8 conditional skips. The real HTTP catalog
  test was enabled with the website validation Python runtime. Independent
  client databases exchanged classification, weights, merges and deletion;
  a fresh client also imported the merged identity.
- Website: 119 passing tests. Atomic merge, stale revision rejection, full
  prior-set membership, retirement preservation, idempotent receipts and
  retry after inventory arrival are covered.
- Static analysis: no compiler errors; 224 existing/new lint information and
  warning findings remain, including missing braces. This is not a clean lint
  result and is not represented as such.
- Egress audit: 133 Dart files, no raw public HTTP constructors. LAN control,
  loopback codecs, local recordings and explicit browser links are exceptions.
- Mac updater isolated fixtures: three-start rollback, healthy-start clearing
  and competing-update lock rejection passed.
- Windows updater fixtures: locked helper copying, scoped watchdog suspension,
  three-start rollback, rejected-version skipping and healthy-start reset passed.
- AirPlay helper: 44 passing tests and one conditional skip.
- Merge dialog: cross-category multi-select, rename, review, save and one
  durable merge event passed. A Chinese-font screenshot was inspected.

## Limitations

Apple Silicon packages are cross-built and their architecture, signing and
archive structure are verified. Native Apple Silicon playback was not tested.
Developer ID signing/notarization are unavailable. Website browser visual QA
was not authorized; localized source/template checks are used. Mainland China
without-VPN throughput and playback have not been tested in this run.

Public package, manual-download and update-feed checks are performed after the
manual GitHub release and mirror complete. Publication is not inferred from a
successful build alone.
