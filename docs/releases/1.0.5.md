# BobTV 1.0.5 (build 91)

## Channel organization

Right-click a channel card or the main video and choose **Merge channels**.
Search the current category or all categories, select multiple channels, then
choose an existing name or enter a new one and select the destination category.
Only merge channels whose actual content you have confirmed is identical.

The operation keeps endpoint identities, provenance, learned weights and
retirement records. Duplicate endpoints are counted once. Manual merges survive
upstream refreshes and synchronize through one atomic public-catalog event;
private subscription addresses remain local. Stale edits are rejected without
partially modifying the public list. Existing merged sets are included as a whole.

Category empty states describe the selected category. Global catalog transfer
counts are confined to the sync badge, labeled as whole-catalog records.
Country tabs read availability only for their own visible routes.

## Server connectivity

Source discovery, refresh and AI classification run on the BobTV server. Desktop
clients receive results from the BobTV HTTPS API without contacting GitHub or AI
providers directly. Playback, programme guides, logos and supported media-service
requests use the service gateway. Loopback codec bridges, LAN casting and local
recordings remain explicit local exceptions.

Regional route selection considers the server-observed access region and recent
regional playback feedback. Global identity and retirement records still apply.
Private origins are rejected, HLS child resources are rewritten and DASH resources
are relayed. The server refreshes idle AI health with a bounded readiness request.
Client AI keys are not needed for server execution.

## Windows fullscreen

Entering fullscreen hides native window chrome even when the window was already
maximized. Leaving fullscreen restores resize and maximize capabilities. Returning
to channels retains the requested window mode. Fullscreen entry, return, re-entry
and picture-in-picture use the same restoration policy.

Windows and macOS retain the lightweight guide: channel name at the upper left,
current and two following programmes in the centre, return and exit at the right.
Guide controls appear on mouse movement and hide with the playback overlay.

## Packages and limitations

Windows x64 Setup and portable ZIP, Intel macOS DMG/update ZIP, and Apple Silicon
macOS DMG/update ZIP are provided. Automatic-update feeds are platform-specific.
macOS apps use ad-hoc signing and BobTV publisher-signed update archives. Apple
Developer ID signing and notarization are unavailable. Apple Silicon packages are
cross-built and structurally checked on the Intel build host; native ARM playback
has not been tested here.

Server relaying does not guarantee Mainland China throughput or source
availability. A Mainland China network probe and local playback test are still
required before making that claim. Test-host checks and public delivery evidence
are recorded in the companion validation report.
