# BobTV 1.0.6+92 validation

Date: 2026-10-12 (Japan local time).

This is a narrow follow-up to the [1.0.5 acceptance](1.0.5-validation.md).
The playback footer reads `PlayerService.currentCandidateCount`; category/card
indexes remain independent. The footer no longer presents an off-category
verified count as zero.

## Automated checks

- Full Flutter suite: 375 passing tests, nine conditional skips. The real HTTP
  catalog test was then explicitly enabled and passed, giving 376 passing tests
  and eight remaining conditional skips across the acceptance run.
- Targeted category/merge/fullscreen tests: 39 passed and one conditional skip.
- Website: 119 passed, with one Starlette/httpx deprecation warning.
- The real HTTP test uses three separate databases and verifies a fresh client
  receives merged identity, category, learned scores and retirement records.
- Intel and Apple Silicon Mac package architectures, deep ad-hoc signatures,
  DMG checksums and BobTV update signatures passed.

## Previous live evidence retained

Installed build 91 showed 40 CCTV channels and 15 Taiwan channels, with per-card
route counts. CCTV-6 live video and the three-programme fullscreen guide were
captured at 3840 by 2160 with native caption inset zero.

Build 91 public publication verified all three platform feeds, four manual
downloads, three update archives, eight GitHub assets and four localized copies.
The website mirror reported `Published 55 mirrored releases` and success.
Both isolated native updaters downloaded build 91 from the public HTTPS mirror,
verified it, backed up build 90 and installed build 91 without touching the live
players. Three-start rollback fixtures passed on both platforms.

## Public delivery

- GitHub `v1.0.6` is published with eight assets. Asset sizes and GitHub digests
  match the local packages.
- The website mirror completed successfully and reported `Published 59 mirrored
  releases`. All three platform update feeds advertise `1.0.6+92`.
- Seven public HTTPS binary downloads, comprising three update archives and four
  manual downloads, were streamed and checked against their complete local
  SHA-256 hashes. All matched. The Windows ZIP uses normalized `/` paths.
- Homepage/download descriptions and four localized copies were deployed with
  the packages. GitHub Actions remain disabled.

## Installed-host update acceptance

- Windows: the actual build 91 application's update screen discovered build 92,
  downloaded the public archive and displayed the ready state while playback
  continued. A mouse click on the application's exit control allowed the native
  worker to back up build 91 and install build 92. The player was then restarted
  explicitly for acceptance testing.
- The running Windows executable reports `1.0.6+92`; every installed package file
  matches the release bundle. Startup-health acknowledgement was recorded after
  30 seconds, the player remained responsive and no application crash events
  were found since that process started.
- Post-upgrade screenshots show 40 CCTV channels and 15 Taiwan channels. With
  CCTV-6 playing, changing the browser from CCTV to Taiwan retains `候选 6 路`
  in the main footer. Taiwan loading uses its own spinner and then its own
  15-channel count; no global `4327/4327` text appears in the category canvas.
  Live CCTV-6 and a silent Beautiful Life TV card preview were both visible.
- Runtime logs recorded a transient Windows RSS peak around 2.4 GiB during
  switching and a subsequent heartbeat around 596 MiB. This release does not
  establish a memory-performance improvement or long-duration soak result.
- Mac: the public build 92 feed and the installed native update worker were
  invoked programmatically. The worker downloaded and verified the archive and
  publisher signature, waited for the authorized player exit, backed up build 91
  and installed build 92. This validates native installation, not GUI discovery.
- The installed Mac bundle reports `1.0.6+92`, its deep ad-hoc signature is valid,
  and the build 91 backup is preserved with a valid signature. The new process
  recorded its 30-second startup-health acknowledgement and continued sending
  heartbeats. On 2026-10-12 (Japan local time), the user confirmed that build 91's
  window and channel list were normal and that build 92's current picture and
  sound were normal. This is user-observed playback acceptance on the Intel Mac.

Apple Silicon native playback, Mainland China without-VPN throughput and public
website browser visual QA remain unperformed. The Mac console is unavailable for
agent-captured native-screen visual acceptance; the user confirmed build 92's
audio/video, and previously confirmed build 90's fullscreen guide and return
behavior. These limitations are separate from the verified public downloads and
native update installation.
