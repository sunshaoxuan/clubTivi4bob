# BobTV 1.0.6 (build 92)

This release retains the server-managed discovery, HTTPS gateway, regional
ranking, shared channel merging and fullscreen improvements in 1.0.5.

The main player's candidate count now comes from its active playback pool.
Browsing another country or category no longer replaces that count with the
browser's local category index. The main footer omits a category-scoped verified
count, which could become misleading when the playing channel was off-screen.
Channel cards and category counts continue to describe their own channels.

Windows x64 Setup/ZIP and Intel/Apple Silicon macOS DMG/update ZIP packages are
provided. The platform-specific BobTV update feeds include this revision.
macOS uses ad-hoc application signing and BobTV publisher-signed updates.
Apple Silicon native playback and Mainland China throughput remain untested on
the current Intel/Japan test hosts. See the companion validation report.
