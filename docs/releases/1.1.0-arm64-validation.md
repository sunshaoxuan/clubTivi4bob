# Windows ARM64 supplement for BobTV 1.1.0

Build: `1.1.0+93`. Cross-compiled on sunsx-pc, an x64 Windows 11 host,
on 2026-10-12. No physical Surface was available.

## Build evidence

- Flutter 3.44.6, Dart 3.12.2, engine
  `83675ed27633283e7fc296c8bca22e841224c096`.
- MSVC 14.44.35207, `HostX64/arm64` compiler, with ARM64 ATL installed.
- The normal Flutter SDK was preserved. An isolated SDK copy forces the
  Windows ARM64 target and uses hash-pinned official engine artifacts.
- The official ARM64 snapshot compiler is an x64 executable; its generated
  Dart AOT is a 64-bit little-endian AArch64 ELF, machine 183.
- The application and all 24 root DLLs have PE machine `0xAA64`. This includes
  Flutter, libmpv, ANGLE, SQLite and every Flutter plugin.
- All packaged ARM64 Microsoft CRT files have valid Microsoft signatures and
  release flags. The x64 `vcruntime140_1.dll` shipped in the ARM64 CRT folder
  is omitted. Import inspection confirms no root binary requires it.
- The modern ANGLE build no longer exposes D3D9. Header/implementation guards
  retain D3D9 for existing x64 headers while ARM64 uses supported D3D11 paths,
  including WARP fallback.
- Native compilation and Inno Setup compilation completed successfully.
- Existing x64 AirPlay and FFmpeg tools remain isolated child-process support;
  they are not loaded as ARM64 application DLLs. Their Surface behavior is
  untested.
- Third-party notices, source references and a CRT file manifest accompany the
  package. Update ZIP paths are normalized to `/` before publication.

- PowerShell syntax, PE selection, mixed-DLL rejection and ELF AOT fixtures pass.
- Website Python suite: 128 passed; one existing deprecation warning.
- OS/CPU download-menu suite: 3 passed.
- The modified rendering source also compiled successfully against the
  existing x64 ANGLE headers using the normal x64 Microsoft toolchain.
- Local metadata validation covers all seven platform packages, including the
  new ARM64 ZIP. Existing Mac publisher signatures remain valid.
- GitHub's 13 asset sizes and SHA-256 digests match the local files.
- Website mirroring completed at 04:13:25 UTC, reporting 68 mirrored releases.
- All seven public update feeds show `1.1.0+93`. Full downloads of all seven
  updater packages and nine manual packages passed size and SHA-256 checks.
- All four localized homepage/download pages contain the ARM64 availability
  and hardware-test caveat. Download JavaScript and stylesheet hashes match

- Post-deployment catalog/gateway tests returned 65,536 media bytes for GOOD TV

## Limits

Surface Setup installation, actual video/audio, GPU stability, AirPlay helper
emulation, automatic update installation and startup rollback still require
Windows ARM64 hardware testing. Android hardware playback and Mainland China
throughput also remain untested. The public download page states these limits.

No installed desktop application was started, stopped or replaced. GitHub
Actions remain disabled. Browser visual review remains unavailable under the
saved browser permission setting.
