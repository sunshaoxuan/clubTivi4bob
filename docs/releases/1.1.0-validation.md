# BobTV 1.1.0 publication validation

Validated on 2026-10-12 for `1.1.0+93`. This supplements the initial tablet
development snapshot in `docs/tablet-validation-20261012.md`.

## Publication

- Source was committed to the `main` branch of
  `sunshaoxuan/clubTivi4bob`; GitHub Actions remain disabled.
- [GitHub release v1.1.0](https://github.com/sunshaoxuan/clubTivi4bob/releases/tag/v1.1.0)
  is public, with 11 assets. Every asset size and GitHub SHA-256 digest matches
  the local release file.
- The website mirror completed successfully, reporting
  `Published 66 mirrored releases` at 03:08:41 UTC.
- The [homepage](https://bobtv.briconbric.com/) and
  [downloads](https://bobtv.briconbric.com/downloads) were updated in Chinese
  Simplified, Chinese Traditional, English and Japanese. Deployed JavaScript
  and CSS hashes match the repository files.
- Downloads use separate Windows, macOS and Android columns, with CPU choices
  inside each operating-system group. Windows Setup and portable ZIP stay
  together; changing the Mac CPU choice does not change Windows downloads.

## Public delivery

All six feeds show `1.1.0+93`, with matching archive sizes and SHA-256 values:
`windows-x64`, `macos-x64`, `macos-arm64`, `android-arm64`, `android-arm`,
and `android-x64`.

Full-file downloads were checked for all six updater URLs and seven manual
downloads: Windows Setup and ZIP, two macOS DMGs and three Android APKs.
All 13 checks matched the published checksums. Android downloads have the APK
MIME type. The unpublished Windows ARM64 feed returns HTTP 404.

The public delivery report is retained outside the source repository at
`outputs/BobTV-v1.1.0/public-delivery-validation.json` in the release workspace.

## Application and server checks

- Final Flutter suite: 387 passed, 8 conditional skips.
- Website Python suite: 125 passed, with one existing Starlette/httpx
  deprecation warning.
- Download-group JavaScript suite: 3 passed.
- Android APK signing, minimum SDK, CPU libraries, ELF load alignment and ZIP
  alignment checks passed. Private signing material is excluded from releases.
- Both Mac CPU bundles and their publisher-signed update ZIPs passed package
  and signature checks.
- Native Windows x64 compilation and Setup creation succeeded. Installation
  fixtures covered Chinese/Japanese paths, desktop shortcut options and
  uninstall behavior. PE checks reject incompatible root DLLs.
- The public catalog snapshot passed its digest check. Post-deployment media
  tests returned 65,536 bytes for GOOD TV through three website gateway hops,
  and CCTV-1 through two. Private upstream URLs were rejected, and the logo
  index returned 1,836 entries.
- The website service is active. Installed Mac and Windows desktop apps were
  not replaced or restarted for this release publication.

## Limits

Xiaomi Pad hardware playback and Android update installation, Mainland China
throughput, and native Surface ARM64 compilation/runtime remain untested.
There is no Surface ARM64 package in this release. In-app update feeds and
downloads were verified; a live upgrade of the currently installed desktop
apps was not performed.

Public browser visual review was blocked by the saved browser permission
setting. Automated grouping and localized-content checks do not establish
that visual review passed.

Mac app bundles use ad-hoc signatures; update archives use BobTV publisher
signatures. Apple notarization is unavailable. Program Files Windows upgrades
require administrator-authorized Setup installation. Android installation
requires system confirmation and has no unattended installation or automatic
APK rollback.
