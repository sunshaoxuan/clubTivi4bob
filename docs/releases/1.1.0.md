# BobTV 1.1.0

Build: `1.1.0+93`.

## Changes

- Initial signed Android tablet APKs for ARM64, ARM32 and x64, minimum Android 7.
- Shared modern simple UI, responsive portrait/landscape layouts, touch menus,
  previews, favorites, channel merging and category edits.
- Aspect-preserving video and smaller bounded tablet playback buffers.
- Safe Android Surface ownership and native picture in picture on supported devices.
- Android website update checks, visible/resumable downloads, integrity and
  publisher validation, followed by Android system installation confirmation.
- Shared website catalog initialization and durable public edits on Android,
  alongside the existing Windows and macOS clients.
- Windows software-rendering aspect ratio correction, protected from Windows
  min/max macros. UTF-8 script validation also supports PowerShell 5.1.
- Native Windows ARM64 Setup and ZIP, cross-built on x64 Windows using a
  version-pinned isolated Flutter SDK. Architecture checks cover the app,
  Dart AOT and in-process DLLs; Surface hardware tests remain pending.
- Download page groups Windows, macOS and Android separately, with CPU choices
  inside each operating-system column. Four localized homepage/download copies
  explain the new platforms and their limitations.

## Distribution

Windows x64 and ARM64 Setup and portable ZIP; Intel and Apple Silicon macOS DMG and
publisher-signed update ZIPs; Android ARM64, ARM32 and x64 APKs. Update metadata
and SHA256SUMS accompany the release. ARM64 packages are selected within the
Windows download column; the page explicitly marks pending Surface hardware tests.

Windows portable and writable Mac installations retain their existing
post-exit updater and startup rollback. Program Files Windows Setup upgrades
require administrator approval. Android installation always requires system
confirmation; detached downloads, unattended APK installation and Android
automatic rollback are not implemented.

## Validation and limitations

The final application suite passed 387 tests, with eight conditional skips.
Android package signatures, ABI/library alignment and minimum SDK checks passed.
Shared-catalog HTTP exchange, server egress and Windows PE architecture fixtures
passed. Website and download-menu tests cover separate OS groups and CPU choices.

Physical Xiaomi Pad playback, Mainland China throughput and Surface ARM
runtime testing remain unperformed. Mac packages are ad-hoc signed and
their update ZIPs use the BobTV publisher signature; Apple notarization remains
unavailable. Public browser visual review is blocked by the saved browser
permission setting. Existing desktop applications are not restarted by publication.
