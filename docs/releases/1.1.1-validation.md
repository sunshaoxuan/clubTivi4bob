# BobTV 1.1.1 validation

Target: `1.1.1+94`. Manual release, with GitHub Actions disabled.

## Application and server tests

- Flutter suite: 427 passed, nine conditional skips. The real shared-catalog
  HTTP test was then run separately with its Python fixture enabled and passed,
  giving 428 exercised passing tests and eight remaining conditional skips.
- Website/API suite: 142 passed. Resource routing and OS/CPU download menus:
  seven JavaScript tests passed.
- Targeted Dart analysis: no errors or warnings; four pre-existing style
  information messages in the route-transfer dialog.
- Isolated public relay checks passed: matching catalog manifests, snapshot
  checksum and cache HIT, preserved regional profile, one canonical upload
  receipt, matching seven-platform feeds, byte-range requests and a complete
  66,829,152-byte archived Windows package. Video and admin relay paths rejected.

## Native packages

- Fresh Universal macOS Runner, Dart AOT, engine, media libraries and plugins
  compiled with Xcode 26.3. Each Intel/Apple Silicon variant checks all 128
  native files, refreshes sender bytecode from current source, and passes deep
  strict app-signature verification.
- Intel Mac native lifecycle checks passed: 20 software-rendering live-frame
  disposal cycles (239 frames), 20 hardware-rendering cycles (227 frames),
  the packaged Metal adapter with 500 callbacks and 4,000 owned frames across
  two streams, resizing and GPU readback. No retained frame backings remained.
- macOS post-exit worker fixture passed, including three-failure rollback,
  healthy-start acknowledgement and concurrent-worker exclusion.
- Both Mac DMGs passed disk-image integrity verification. Both update ZIPs
  passed the existing BobTV publisher-key verification.
- Android ARM32, ARM64 and x64 APKs passed signature verification with the
  existing certificate SHA-256
  `163f6e8d1474816420774d24ac3c08e7b5ac5d00759d65e0d2c1e517684bb714`.
  Their minimum SDK is 24 (Android 7); architecture-specific version codes are
  1094, 2094 and 4094.
- Windows packages are built on sunsx-pc, using the validated isolated SDK
  for ARM64 cross compilation. Package assembly includes current sender source,
  Microsoft runtime checks and isolated Unicode-path installer fixtures.
  Both build jobs passed. Normalized ZIPs passed CRC checks, Dart AOT CPU checks,
  and all in-process PE checks (29 x64 files and 25 ARM64 files).
- Two additional frozen macOS sender packaging tests passed.

## Publication acceptance

Publication is accepted only after the final package inventory, SHA-256 list,
GitHub assets, mirror-service success, public downloads, localized pages and all
seven update feeds are checked. Public results are recorded after publication.

Installed BobTV applications are kept running. Native Surface ARM64 and Xiaomi
Pad hardware playback, Mainland China network throughput, Apple Silicon runtime
testing and public browser visual acceptance remain unperformed. Mac packages
are ad-hoc signed without Apple Developer ID notarization. This run validates
update delivery and isolated installer/rollback behavior; it does not upgrade
or restart an installed desktop application.
