# BobTV 1.1.1

Build: `1.1.1+94`.

## Changes

- Adaptive resource delivery through the primary BobTV site and the cndrp.com
  resource cache. Clients compare complete probe transfers, retain a recent
  selection and fall back when a resource node fails. Public catalog mutations
  still reach one canonical database. Video streams connect directly to their
  original sources and never pass through the cndrp resource cache.
- Transfer a single incorrectly assigned route to another channel from player
  and channel-card menus. Search across categories, preserve source provenance
  and health records, deduplicate equivalent URLs, and synchronize public moves
  through the shared catalog. Private subscriptions remain local.
- Desktop startup and normal-window restoration respect the current display's
  available work area. The complete window frame is capped at 1920 by 1280
  physical pixels, including display scaling. Explicit maximization,
  fullscreen playback and picture in picture retain their own behavior.
- Updated homepage, download instructions and release notes in Simplified
  Chinese, Traditional Chinese, English and Japanese.

## Packages and updates

Windows x64 and ARM64 Setup installers and portable ZIPs; macOS Intel and Apple
Silicon DMGs and publisher-signed update ZIPs; Android ARM32, ARM64 and x64 APKs.
Publisher metadata and SHA-256 checksums accompany the packages. Downloads
remain grouped by operating system, with CPU choices inside each group.

Windows Program Files installations require administrator approval when
running the new Setup installer. Portable Windows and writable macOS
installations retain post-exit updates and startup rollback. Android upgrades
require the system installation confirmation. macOS packages are ad-hoc signed
with a separate BobTV publisher signature for updates; Apple notarization is
unavailable.

## Verification and limitations

Detailed build, test, signature and public-delivery results are recorded in
`1.1.1-validation.md`. Publication does not restart installed applications.
Physical Windows ARM64 Surface and Xiaomi Pad tests remain pending. Mainland
China download throughput and playback require testing on a local network.
