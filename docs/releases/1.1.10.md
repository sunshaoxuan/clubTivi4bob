# BobTV 1.1.10

All released platforms use `1.1.10+103`: Android ARM/ARM64/x64, Windows
x64/ARM64 and macOS Intel/Apple Silicon. They are built from one source tree.

- Add optional incremental sync of up to 30 days of available redacted
  diagnostics. New explicit consent is required, including for users who opted
  into the older short summary. Disable it at any time in public-service settings.
- Upload only allowlisted event, version, platform, request-stage, node, timing,
  status and resource metrics. Never upload raw exception text, stacks, media
  addresses, credentials, private subscriptions, favorites or viewing content.
- Use a private, bounded, persistent cndrp queue for mainland China. Relay
  storage and authoritative origin acceptance have distinct receipts. Exact
  body hashes, restart recovery, idempotency, backoff and event-age expiry protect
  uploads. Already received data expires within 30 days of the oldest event.
- Recover resource GET requests after connection, response-header or body
  timeout, switching approved nodes once. Abort failed requests and discard
  incomplete bodies. Never blindly replay a mutation after sending its body.
- Queue catalog events during temporary writer contention, preserving their
  event IDs. Retain the client outbox until canonical application is confirmed.
  Cached receipts and read-only WAL queries keep catalog reads available.
- Android receives the common catalog, channel presentation and EPG logic from
  the same source as the desktop builds. Desktop window pinning and native
  fullscreen remain platform-specific controls.
- Keep the Windows update progress window responsive if its diagnostic log
  is locked or cannot be written. This incorporates the existing isolated
  Windows-tested fix. Physical installer acceptance remains unverified.

Private sources, manual EPG mappings, favorites and offline caches are retained.
Publication does not install or restart applications on users' devices.
Headless tests do not establish Canadian network performance or physical
playback acceptance. Apple notarization and trusted Windows Authenticode
signing remain unavailable; publisher signatures protect update packages.
