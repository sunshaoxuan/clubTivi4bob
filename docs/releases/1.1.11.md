# BobTV 1.1.11

Windows x64/ARM64, macOS Intel/Apple Silicon and Android ARM32/ARM64/x64
all use `1.1.11+106`, built from application commit
`9bd1e25e26b426af66dbc243cf802e18edfa0bc3`.
The Android supplement retains the existing APK publisher certificate.
Previously published desktop binaries remain byte-for-byte unchanged.

- Restore EPG matching and programme expansion on channel cards across channel
  types, including public and personal channels. Use configured identifiers and
  channel names while preserving explicit manual mappings. Show current and
  upcoming programmes when matched data is available, and display distinct
  missing-data or loading-failure states when it is not.
- Skip invalid XMLTV programme records individually so one malformed programme
  cannot discard the remaining valid import. Retain custom sources and their
  configured automatic refresh, alongside public guide updates and local caches.
- Drain background EPG, catalog and player work, then await the idempotent
  database close before tearing down native desktop windows and the Flutter
  engine. This fixes the shutdown ordering used for automatic-update exits.
- Do not read Keychain credentials for disabled features. Non-interactive access
  does not request authorization dialogs; a denied request pauses automatic
  access persistently until the user explicitly resumes authorization. Preserve
  credential identity checks during upgrades.
- Space out failed catalog sync retries so pending work does not rapidly toggle
  the status indicator. Retain local edits until the server confirms application.

Guide coverage depends on the configured sources and their available schedules.
The shared matching and presentation fixes apply across channel types; they do
not create programmes that an upstream source has not supplied. Private sources,
manual EPG mappings, favorites and offline caches are retained.

Optional diagnostic sync remains off by default and requires explicit consent,
including for users of the older short summary. It sends only allowlisted,
redacted records from at most 30 days and can be disabled at any time. Raw
exception text, stacks, media addresses, credentials, private subscriptions,
favorites and viewing content remain excluded.

Windows installations download and verify Setup in BobTV and request
administrator approval when installation is selected. Portable Windows and
writable macOS installations update after exit; protected macOS locations need
manual replacement. The shutdown fix takes effect when 1.1.11 is running. The
first upgrade from an older build still uses that build's exit implementation.
Publishing the release does not install or restart applications on users' devices.

macOS DMGs are hosted on the BobTV site. The application is ad-hoc signed,
without an Apple Developer ID signature or Apple notarization. Automatic-update
ZIPs use a separate BobTV publisher signature and SHA-256 verification. These
checks do not provide a stable Apple Developer ID identity or remove all macOS
first-launch and authorization prompts. Trusted Windows Authenticode signing
remains unavailable. See the [signing policy](../code-signing-policy.md).

Android validation checks the existing release certificate, actual package version, ABI, native library alignment and package integrity. Android and shared EPG regression: 52 passed. Physical Android playback and on-device installation were not tested in this run. Future official releases require all seven platform versions and base builds to match.
