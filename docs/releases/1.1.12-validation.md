# BobTV 1.1.12 release validation

Version: `1.1.12+107`. All seven platform variants were newly built and published together: Windows x64/ARM64, macOS Intel/Apple Silicon, and Android ARM32/ARM64/x64.

## Source and regression checks

- Final source: `f1fe76d08df49596bbe26e16d8b52ad6e20bd023`.
- Application inputs are identical to `d52afeb19e5f7c14539b39ca590c5e3d622d537f`. The follow-up commit changes only the catalog server integration and its hierarchy regression. The final Mac source rebuild produced identical application bytes.
- Final client regression: 842 passed, 22 environment-gated skips, no failures. Windows focused regression: 205 passed, 4 skips; architecture, update helper, rollback, progress, publisher-signature/tamper and managed-update fixtures passed.
- Server and release template/alignment regression: 56 passed. Additional catalog/inventory regression: 46 passed.
- All 1,059 frozen source files were verified on Windows, including the two documented UTF-8 BOM packaging transformations. Existing Windows process/files and installed Mac application files were preserved.

## Packages

- Exactly 13 assets, with seven matching version/base-build entries, passed `tools/verify_release_alignment.py`.
- Windows PE architecture, section structure, embedded versions, native media library identity, updater assets, ZIP contents and installer publisher signatures were verified for both architectures.
- Both Mac app variants, DMGs and update ZIPs passed architecture, strict ad-hoc code-signature, DMG trailer/image, bundle-content and BobTV publisher-signature checks.
- Android APKs retain the existing publisher certificate. ARM32/ARM64/x64 native libraries, package integrity and alignment were verified. Embedded versionName is 1.1.12; versionCodes 1107/2107/4107 encode common base build 107.

## Public delivery

- [GitHub release](https://github.com/sunshaoxuan/clubTivi4bob/releases/tag/v1.1.12): all 13 asset sizes and SHA-256 digests matched finalized local packages.
- Mirror completed with Result=success and exit status zero; journal confirmed `Published 170 mirrored releases`.
- Main site: all seven update feeds, nine manual range requests and eighteen complete-body download paths matched the release.
- External relay: seven feeds and nine range requests passed. The cache host verified eighteen complete-body paths over HTTPS. This does not measure external regional download throughput.
- All twelve localized homepage/download/diagnostic pages passed version, release-copy and consent-policy checks. Website content was deployed atomically with backup; runtime module hashes and the EPG service were preserved.

## Validation limits

Physical ARM desktop and Android installation/playback were not tested. Browser visual QA was not performed. Mac packages use ad-hoc application signing with a separate BobTV publisher signature for update ZIPs; Apple Developer ID/notarization and trusted Windows Authenticode signing remain unavailable.
