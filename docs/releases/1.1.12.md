# BobTV 1.1.12

Windows x64/ARM64, macOS Intel/Apple Silicon and Android ARM32/ARM64/x64 use **1.1.12+107**, built from the same application source commit.

- Normalize country and region aliases to Simplified Chinese and merge equivalent category branches.
- Show Other at the top level. Unidentified channels no longer appear under China / Other.
- Separate television and radio below each international country or region. Distribute legacy radio entries using their recorded country metadata, keeping entries without country information in Other for review.
- Preserve channel IDs, stream routes, guide identifiers, favourites and manual category choices. Keep the EPG, credential and shutdown fixes shipped in 1.1.11.
- The server reviews small batches for geography and service type, applies sufficiently confident results, and retains uncertain entries for review. Remove the unconfigured hourly/daily AI request cap; retry according to actual upstream responses.

Classification metadata can still need review, and stream availability depends on the source.

macOS uses ad-hoc application signing and separately publisher-signed update ZIPs; Apple Developer ID signing and notarization remain unavailable. Windows Authenticode signing remains unavailable. Android retains its existing release certificate. Native ARM hardware installation and playback are not claimed by package/architecture validation. Publication does not install or restart existing user applications.
