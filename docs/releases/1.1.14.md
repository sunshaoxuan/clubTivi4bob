# BobTV 1.1.14

All seven platforms use **1.1.14+109**: Windows x64/ARM64, macOS Intel/Apple Silicon, and Android ARM32/ARM64/x64.

- Measure a real 128-band FFT spectrum from decoded PCM audio using the shared pass-through native filter. The analysis forwards the original audio frames unchanged.
- Show live radio spectrum in the main player and muted preview cards. Muted previews measure the source before output volume; the main player follows output mute, volume and pause state. Silence produces zero bars.
- Retain the radio surface when entering fullscreen by double-clicking. Adapt to 16, 32, 64 or 128 bars by display width, with bar width capped at three logical pixels.
- Preserve existing filters when attaching and removing spectrum analysis, and combine stereo channel energy without cancelling opposite-phase signals.
- Pin the Android and Windows native runtime archives by SHA-256 in `tools/native/runtime-lock.json`. Android retains the pinned media-kit runtime with the added filter; Windows uses architecture-specific shared libmpv/FFmpeg runtimes. macOS rebuilds the matching FFmpeg filter ABI during packaging.

All official application packages use one frozen application commit. Native runtime manifests retain their dependencies, architecture and common filter source hash. The Android x64 emulator and Windows x64 signal probes exercise the packaged native library. Package and emulator checks do not imply physical Android, Windows ARM64, or Intel Mac playback validation.

macOS applications remain ad-hoc signed, with separately publisher-signed update ZIPs. Apple Developer ID signing/notarization and trusted Windows Authenticode signing remain unavailable. Android retains its existing publisher certificate. Publication does not restart installed applications. Optional diagnostic sync remains off by default and requires explicit consent for at most 30 days of redacted records.
