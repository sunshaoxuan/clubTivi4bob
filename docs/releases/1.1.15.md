# BobTV 1.1.15

All seven platforms use **1.1.15+110** from one application source commit:
Windows x64/ARM64, macOS Intel/Apple Silicon, Android ARM32/ARM64/x64.

- Retry temporary Windows update download failures up to three attempts, with
  bounded waits and unchanged URL, hash, size and publisher-signature validation.
- Publish a verified completion receipt when the portable installation already
  contains the requested target version, and reread terminal receipts after
  observing helper exit to avoid a stale progress/error result.
- Keep update-window button text white, add an explicit close control and Escape
  handling, and retain verified-launch requirements and automatic completion close.
- Combine confirmed mainland region paths for navigation. Include all matching
  programme subgroups in database queries without exposing those subgroups as
  regions. Preserve stored groups, channels, favorites and manual classifications.
- Bound server automatic assignments to confirmed geography, retaining media
  distinctions and programme-type evidence outside the region selector. Unknown
  geography remains pending. No bulk deletion of user data is performed.

Native FFT source and its checksum-locked dependency runtimes are unchanged from
1.1.14; all seven application packages are rebuilt for this release. macOS remains
ad-hoc signed with publisher-signed update archives; Apple Developer ID notarization
and trusted Windows Authenticode signing are not claimed. Android retains its
existing publisher certificate. Publication does not restart installed applications.
