# BobTV 1.1.16

All seven platforms use **1.1.16+111** from one application source commit.

- Keep favorites and category subsets on the same authoritative public channel identity, including services with inconsistent route labels.
- Retain national overview/genre grouping: a channel listed in CCTV or Digital and a recognized programme genre occupies one favorite card, with canonical route addresses deduplicated.
- Reconcile existing favorite memberships without deleting channel records or requiring users to remove and re-add favorites.
- Preserve country, region, UHD, guide, radio, time-shift and explicit manual merge distinctions. Ambiguous services remain separate.

Windows x64/ARM64, macOS Intel/Apple Silicon and Android ARM32/ARM64/x64 are rebuilt from the same source. Native FFT dependencies remain pinned to the validated runtime hashes. Package checks do not establish physical-device playback acceptance. macOS uses ad-hoc signing with publisher-signed update archives; Apple notarization and trusted Windows Authenticode signing are not claimed. Android retains its existing publisher certificate. Publication does not restart installed applications.
