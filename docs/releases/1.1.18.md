# BobTV 1.1.18

Windows x64/ARM64, macOS Intel/Apple Silicon and Android ARM32/ARM64/x64 use **1.1.18+113**, built from the same frozen application source already pushed to main.

- Public channel browsing reads the selected country or category, reuses a bounded cache and shares identity metadata with the alternative-route index. Country navigation remains complete. Large identity calculations run outside the UI isolate.
- Stored favorites display before historical reconciliation. A star click removes a channel from favorites, with Undo; list-management checkbox changes are serialized and persist correctly. Distinct services, private sources and manual merges remain protected.
- Expired server-guide status no longer overlays normal playback. Affected channel guides and settings retain useful status, coverage and retry details. Background version checks, offline cache and manual mappings remain intact. This release does not claim that unavailable programme data has been restored.

## Validation boundaries

Windows x64 and macOS Intel use isolated native acceptance with the production channel screen and native decoder. Owned audio-free video, muted volume and null audio output protect the user's audio environment. The fixture tests country-scoped queries, warm-cache switching, guide hot updates and native player continuity, independently of installed applications and personal data. Favorites also use the native interactive acceptance fixture.

Android physical-device testing is waived by the user. Build, shared automated tests, APK signatures, embedded versions and all three ABI payloads remain publication gates. Windows ARM64 and macOS Apple Silicon receive build/package validation; this run does not claim physical ARM64 desktop testing.

macOS uses ad-hoc application signatures and publisher-signed update archives. Apple notarization and trusted Windows Authenticode signing are not claimed. Android retains its existing publisher certificate. Publication does not install or restart the user's running applications.
