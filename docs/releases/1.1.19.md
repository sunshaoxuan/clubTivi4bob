# BobTV 1.1.19

Windows x64 and ARM64, macOS Intel and Apple Silicon, and Android ARM32, ARM64 and x64 share version **1.1.19+114**.

- The app and website support English, Simplified Chinese, Traditional Chinese, Japanese, French, Spanish and Korean.
- Select a language from the globe menu in the app. The app remembers manual selections. Automatic mode checks the system language, then the time zone, and uses English when neither can select a supported language.
- Every package includes the same seven language resources for offline use. The advanced mode entry is closed.
- Requests for public pages, assets and downloads from mainland China use the BobTV mirror.
