# BobTV 1.1.2

Build: `1.1.2+95`.

## Changes

- Create missing countries, regions and nested categories directly in the
  category editor. Existing names are reused, repeated clicks do not duplicate
  the path, and canceled drafts are discarded. Public edits upload in the
  background. The server and clients retain the complete category hierarchy.
- Keep the channel-panel synchronization badge and count at the right edge.
- Back up favorites in a device-private namespace. Restoration requires the
  original device fingerprint and its securely stored secret. Favorites never
  enter the public channel catalog or another device's favorite lists.
- Prevent globally retired routes from being reopened through fallback,
  preview promotion, recovery or refreshed source lists. Successful reports
  from another device cannot revive an explicitly retired route.
- Download publisher-verified Windows Setup updates inside BobTV for managed
  installations. Show download, verification, authorization, installation and
  recovery states. Canceling administrator authorization keeps the old app
  running and the downloaded update available. The installer waits for the old
  process before replacing files; launch is enabled only after validation.
- Refresh the homepage, downloads and release descriptions in four languages.

## Packages and updates

Windows x64 and ARM64 Setup installers and portable ZIPs; macOS Intel and Apple
Silicon DMGs and publisher-signed update ZIPs; Android ARM32, ARM64 and x64 APKs.
Downloads stay grouped by operating system and then CPU. Metadata and SHA-256
checksums accompany every release.

Program Files installations still require Windows administrator approval.
Older managed clients need a one-time installation of this Setup to receive
the improved in-app update flow. Portable Windows and writable macOS locations
retain post-exit updates and startup rollback. Android upgrades require system
confirmation. macOS uses ad-hoc app signing and BobTV update signatures, without
Apple Developer ID notarization. Windows installers have a BobTV update
signature, without trusted Windows Authenticode signing; Edge reputation
warnings on a first browser download may therefore remain.

## Verification and limitations

See the [validation report](https://github.com/sunshaoxuan/clubTivi4bob/blob/main/docs/releases/1.1.2-validation.md)
for packaging and public-delivery evidence. Installed
applications are not restarted by publication. Native Windows ARM64 Surface,
Xiaomi Pad and Apple Silicon playback, Mainland China throughput, and real
user approval of a protected-installation update remain hardware or
interactive validation requirements.
