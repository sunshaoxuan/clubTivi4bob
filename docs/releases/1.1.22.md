# BobTV 1.1.22

版本：1.1.22+117

- 在线线路状态同步失败时继续使用本地缓存播放，保留已知淘汰记录，避免连续同步请求拖慢切台。字幕服务尚未就绪或播放失联时回退原始频道线路。
- 修正 EPG“接下来／随后”提示的七语显示，以及长文字下全屏操作按钮的布局。
- 国家/地区选择列表跟随界面语言排序，修正日文五十音、韩文字母和重音字母索引；繁体中文采用笔画索引。
- 扩展官方节目单采集与核验，新增七个 Pluto 频道，并修正三台证据充分的地区归属。
- 接入 Action Movies 英国版直播外部字幕试点。支持七种字幕语言偏好，依指定语种、英文、无字幕选择。其他频道保留内嵌字幕选择。
- 广告期间自动暂停影片字幕，正片恢复后验证素材时间连续性，并用新语音样本复核同步。
- 改善一秒广告分片的播放缓冲，字幕位置跟随实际视频显示区域。

适用平台：Windows x64/ARM64、macOS Intel/Apple Silicon、Android ARM32/ARM64/x64。

字幕试点当前使用英语音轨进行语音校准，字幕来自现有文件，译文质量尚未人工审核。原生 Mac 开发客户端已完成一次真实 150 秒广告恢复测试，其他平台的构建与检查结果单独记录。此结果不代表所有频道和广告形式均已验证。Mac 安装包延续既有自托管签名方式。
