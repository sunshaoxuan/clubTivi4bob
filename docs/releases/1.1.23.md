# BobTV 1.1.23

版本：1.1.23+118

- 播放器显示七语字幕状态：正在查找、准备中、同步中、暂未找到、服务暂不可用、缺少节目信息、插播暂停及英文回退。
- Action Movies 英国版由服务器自动检索、重试和同步，冷启动后自动接入就绪字幕，无需手动重选频道。
- 字幕资源按经核验的影片身份、版本及七种语言持久缓存。IMDb ID 可确认时优先使用，其他情况使用官方影片 ID 或片名与年份。
- 同一影片的并发请求合并检索；缓存命中可直接复用文件，内容损坏会校验并重新获取，临时失败保留已有英文字幕。
- 缓存保存字幕文件及来源，直播偏移会在每次播放重新校准。服务异常时继续使用原始频道线路并在后台重试。
- 客户端通过 BobTV 服务及中继接收状态与字幕，不直接调用 GPT。本版自动检索使用现有字幕源适配器。

适用平台：Windows x64/ARM64、macOS Intel/Apple Silicon、Android ARM32/ARM64/x64。

外部字幕继续以 Action Movies 英国版为试点，字幕可用性取决于影片和版本。语音校准使用服务器英语音轨，现有译文未逐条人工审核。其他频道使用内嵌字幕选择和缺失状态提示。
