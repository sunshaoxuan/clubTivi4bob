# BobTV 1.1.3 validation

Target: `1.1.3+96`. Manual staged publication, without automatic GitHub builds.

## Application tests

The compact layout covers 640x360, 800x400, 960x400, 640x480, 800x480, 800x600,
960x540, 1024x600, 1024x768, 1280x720, 1280x1024, 800x1280, 600x960 and 360x640
logical-pixel viewports. Tests check equal split-pane widths, three category rows,
selected overflow options, complete card/EPG visibility, menu attachment and
selection, upward menus near the bottom edge and larger text at 800x600.
Connected outlines are tested at every compact column position.

Android exit tests cover immediate feedback, task removal, bounded cleanup,
provider teardown, decoder cleanup, retries and desktop/PiP isolation.

Flutter regression suite: 525 passed, 11 conditional skips. Targeted analysis
of the responsive presentation components and tests has no issues. The large
existing channel screen retains legacy lint/unused-member warnings, without
compilation errors. Local visual checks rendered 640x360, 800x480, 1024x600 and
1280x720 layouts and their attached menus.

Website/API and Mac-helper packaging suite: 167 passed. Download CPU menus and
resource-node routing: seven JavaScript tests passed. Tests retain the old
Windows downloads and label them while the newer Mac/Android packages are shown.

## Native packages and update checks

- A fresh Universal macOS app was compiled with Xcode 26.3, then split into
  Intel and Apple Silicon apps. All 128 native files in each app passed CPU
  checks. Current sender source was refreshed and deep strict signatures passed.
- Both DMGs passed disk-image checksum verification and retain the existing
  drag-to-Applications layout. Both update ZIPs passed BobTV publisher-signature
  verification. The private signing key remains outside the repository.
- Intel software-rendered and hardware-rendered lifecycle fixtures each passed
  20 live decoder disposal cycles, with 237 and 231 frames respectively. The
  packaged Metal adapter passed 500 callbacks and 4,000 owned frames across
  two streams, resizing and GPU readback, without retained backings.
- The isolated macOS updater fixture passed three-failure rollback, healthy
  startup acknowledgment and concurrent-worker exclusion. Installed apps were
  not restarted or replaced.
- Android ARM32, ARM64 and x64 packages passed package identity, ABI, signature,
  alignment and private-build-file checks. Minimum API remains 24/Android 7.
  The existing publisher certificate is retained. ABI version codes increase
  to 1096, 2096 and 4096.
- All five available platform update packages passed final metadata validation.
  Windows packages are deferred while sunsx-pc is offline. No old Windows
  package is renamed as 1.1.3, and its existing feed remains available.

## Public delivery

GitHub release `v1.1.3` is public and marked latest, with nine assets matching
local byte counts and SHA-256 hashes. Its tag points to source commit
`2e448271656baa975b2d5bb1ec1ed316562f00e2`. The published set comprises two DMGs,
two Mac update ZIPs, three Android APKs, shared metadata and SHA-256 checksums.
Windows will be added to this release after a separate build and verification.

The main mirror completed successfully at `2026-10-13 14:31:21 UTC`, reporting
`Published 91 mirrored releases`. New files were transferred first; revalidation
of historical packages accounted for most of the publication wait.

The website's ten modified content files were deployed with backups at
`/opt/bobtv/backups/website113-20261013T141907Z`. API runtime SHA-256 stayed
`6953c57c56cc7b499bb658ea20d7870239605d66c2b88929d3b72aae9df07354` before and after
deployment. Existing APIs, device registration, channel data and resource routing
were retained. All 12 public localized pages passed content checks, including
the staged-release explanation and corrected signing status.

Primary-site and cndrp acceptance passed:

- Ten new latest feeds and ten matching versioned manifests, covering five
  Mac/Android variants on both nodes.
- Four Windows latest feeds retained `1.1.2+95`, with unchanged archive/Setup
  hashes; the four existing Windows file variants remained downloadable.
- Eighteen public HTTP range requests returned the requested 4,096 bytes.
- Twenty complete downloads across manual and updater URLs matched byte counts
  and SHA-256 hashes. All ten cndrp bodies subsequently reported cache HIT.
- The public channel-catalog manifest remained reachable.

Metadata and range checks used public DNS. Full-body reads used production TLS
virtual hosts with the verified primary origin address and the cache host's
loopback listener; normal TLS hostname/certificate verification remained enabled.
This verifies integrity and cache readiness, without measuring Mainland China
end-user throughput. Machine-readable evidence is in `outputs/BobTV-v1.1.3`.

Physical Xiaomi Pad and Apple Silicon playback, Surface ARM64 behavior and
Mainland China throughput remain untested. Browser visual acceptance of the
website remains unavailable because of the saved browser permission restriction.
Packaging tests do not constitute an installation or update on a user's device.

## Windows completion on 2026-10-14

Windows x64 and ARM64 application bundles were built from the same application
source as the staged Mac/Android packages. The release tag remains
`2e448271656baa975b2d5bb1ec1ed316562f00e2`. New client synchronization and favorite
fixes on main are deliberately unreleased and are not included in these bundles.

Both native application PE/AOT architectures and embedded `1.1.3+96` versions
passed checks. Normalized x64/ARM64 ZIPs contain 706/742 entries and 29/25
application-process native files respectively; all CRC checks passed. ARM64
uses the validated isolated cross-build adapter on sunsx-pc. Physical Surface
ARM64 playback remains untested.

An installer compatibility failure was found before Windows update feeds were
published: the textual Setup version used a plus sign, while existing update
workers expect dotted numeric version resources. Both Setups were rebuilt with
`1.1.3.96` version resources and re-signed with the BobTV update publisher key.
The first mirror run was stopped and both public Windows feeds remained on
`1.1.2+95` throughout that correction. No previously published Mac/Android
binary was replaced. BobTV's main executable still reports `1.1.3+96`.

The corrected Setups passed Windows CNG signature checks. Isolated installer
fixtures passed Chinese/Japanese paths, optional desktop shortcuts, Start menu
creation, waiting for the authorized old process, uninstall and the new version
resource regression check. Managed updater fixtures passed cached official
Setup verification, authorization cancellation preserving current files, distinct
retry request IDs, consent/exit sequencing, signed rollback delegation and
failed-install restoration. Actual elevated launches were mocked at the test
boundary; no installed application was upgraded or restarted.

Website/API tests: 166 passed. Download/resource JavaScript tests: seven passed.
All 12 localized page checks passed after content deployment with backup at
`/opt/bobtv/backups/website113windows-20261013T163855Z`. The customized API entry
point remained byte-for-byte identical. Machine-readable Windows completion
evidence is retained in `outputs/BobTV-v1.1.3/windows-completion`.

Separately, the main-branch fixes passed 533 Flutter tests with 11 conditional
skips, 30 targeted tests, and eight real-HTTP synchronization/regional tests.
The live retirement API was tested through both primary and cndrp endpoints,
with no-store headers and cndrp BYPASS. The maintainer chose to publish only
the Windows 1.1.3 additions and defer a subsequent application release.
