# BobTV 1.1.3

Build: `1.1.3+96`. This release is published in stages.

## Changes

- Add a persistent, touch-sized Android **Exit BobTV** control across startup,
  channel browsing, settings and fullscreen playback. Closing shows immediate
  feedback, stops players and background work, and removes the application task.
  Native Android picture in picture continues to use the system close control.
- Use equal-width player and browser panes on compact split views. Very narrow
  windows stack them vertically. Video keeps its source aspect ratio.
- Limit compact category navigation to three single-line levels. The selected
  option stays visible; More opens a scrollable menu attached to its button,
  containing every option at that level. Selection closes the menu immediately.
- Resize channel cards and connected programme timelines to preserve a complete
  preview and guide. Very short windows use smaller labels and move search to a
  search button. Windows and macOS use the same responsive presentation policy.
- Keep advanced mode and route refresh accessible in the compact toolbar menu.
  Existing favorites, classification, merge, preview and route actions remain.
- Update the download page to label older platform packages during staged
  publication. Correct the signing status: the SignPath Foundation application
  was not approved; no trusted Windows signing certificate has been obtained.

## Available packages

- Android ARM32, ARM64 and x64 APKs, Android 7/API 24 and later.
- macOS Intel and Apple Silicon drag-to-Applications DMGs, plus separately
  publisher-signed update ZIPs.
- Windows x64 and ARM64 remain on `1.1.2+95` while sunsx-pc is powered off.
  Their download links and update feeds remain intact. After compilation and
  verification, `1.1.3+96` Windows Setup/ZIP packages will be added to this same
  GitHub release and mirrored to the download site and cache node.

Every published package is accompanied by SHA-256 checksums and platform-specific
update metadata. Android upgrades require system installation confirmation;
writable macOS installs update after exit. Protected macOS locations require
manual replacement. Mac apps remain ad-hoc signed without Apple Developer ID
notarization. The existing Windows packages lack trusted Authenticode signatures.

## Validation and limitations

See the [validation report](1.1.3-validation.md) for build and public-delivery
evidence. Installed desktop applications are not restarted by publication.
Xiaomi Pad, native Surface ARM64, Apple Silicon playback and Mainland China
throughput still require hardware or local-network testing.
