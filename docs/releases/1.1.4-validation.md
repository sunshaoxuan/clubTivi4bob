# BobTV 1.1.4 validation

Target: `1.1.4+97`, manual release. Package and public-delivery acceptance passed.
Installed clients were not restarted by this publication.

## Source and application checks

- Flutter regression: 606 passed, 11 environment/opt-in skips. Focused analysis
  of 11 changed layout/fullscreen source and test files found no issues.
- Website/API and Mac helper packaging: 168 tests passed. Seven download-menu
  and resource-router JavaScript tests passed.
- Layout checks cover all three platform themes, low/boundary/4K sizes,
  safe areas, resizing, display scaling, menus, preview and connected EPG.
  Prior explicit visual rendering generated 36 previews; Mac 1290x747,
  Windows 1366x768 and Android 800x480 were inspected.
- The authorized local Intel Mac test installation passed real native Escape,
  repeated fullscreen re-entry, double-click return and the Return button.
  Re-entry completed in about 0.74 to 0.76 seconds. Return processing completed
  in about 2 to 35 milliseconds, excluding event delivery and animations.
  Native fullscreen and normal-window bounds were independently read.
- Packaged Intel Metal adapter: 500 runtime callbacks and 4,000 owned frames,
  two streams, resize and GPU readback passed with no retained backings.
  Native disposal fixture: 20 MPV destructions while Flutter textures remained
  retained passed; this fixture did not decode live video.
- Isolated Mac update-worker tests passed three-failure rollback, healthy-start
  acknowledgment and concurrent-worker exclusion.
- Live primary and cndrp probes returned the expected 65,536 bytes. Catalog
  manifests matched. All 19 current permanent-retirement records returned by
  the selected live-state requests matched, with no-store and cndrp BYPASS.
  These checks did not change public channels or scores.

## Package checks

A fresh Universal Mac app was compiled with Xcode 26.3 and split into Intel
and Apple Silicon bundles. Every one of the 128 native files in each bundle
passed CPU verification. Architecture-specific AirPlay dependencies were
retained, frozen sender policy was refreshed from current source, and the
new update-progress helper was compiled separately for each CPU. Both apps
passed deep strict ad-hoc signing. Both DMGs passed disk-image checksums and
retain the drag-to-Applications layout. Both update ZIPs passed the existing
BobTV publisher signature checks. No private signing key enters the repository.

Android ARM32/ARM64/x64 APKs passed identity, original signing certificate,
native ELF architecture, 16 KiB alignment, CRC and private-file exclusion.
Minimum API remains 24/Android 7. Version codes are 1097, 2097 and 4097.

Windows packages are built on sunsx-pc in an isolated release directory,
without replacing an installed app. Source input SHA-256 is
`c18a0374c2f0da638ae2a9a778ede895b9036953dfe58d4de74a04c1735f78cb`.
Windows ARM64 uses the existing isolated, version-pinned x64 cross-build adapter.
Both Windows builds completed successfully. Native PE and Dart AOT architectures
and embedded `1.1.4+97` versions passed inspection. Normalized ZIPs have 706/742
entries and 29/25 application-process native files for x64/ARM64, with valid CRCs.
Setup numeric version resources are `1.1.4.97`; expected Inno string padding is
trimmed exactly as in the real update worker. Both actual Setup files passed
publisher signature verification through Windows CNG. Installer fixtures passed
waiting for an old process, Chinese/Japanese paths, optional desktop shortcuts,
Start menu creation, launch-shortcut policy and uninstall. No installed app was
replaced or restarted. All seven platform packages passed final metadata,
structure and signature validation; the release comprises 13 files.

Two isolated real-HTTP fixtures passed cross-client classification, health and
deletion exchange, original-device favorites restore, other-device denial and
exclusion of favorites from the public catalog.

## Public delivery

GitHub release `v1.1.4` is public and marked latest. All 13 asset sizes and
SHA-256 digests match the local package set. Its immutable source tag points to
`e16a806aaebb8a9a6cccd781a23b4d9dff989a50`; subsequent documentation commits
record delivery without changing that package source.

The primary mirror finished on 2026-10-14 at 03:21:29 JST, with `Result=success`,
`ExecMainStatus=0` and `Published 104 mirrored releases` in its journal. Final
primary-site and cndrp acceptance passed:

- 14 latest feeds, covering seven platform variants on both nodes, all showing
  `1.1.4+97`, with 14 identical matching historical-version manifests.
- 18 manual HTTP range requests, returning the requested 65,536 bytes.
- 36 complete manual/updater downloads with matching byte counts and SHA-256.
- All 18 cache-node download results reported HIT after warming.
- Fresh retirement reads remained no-store and cndrp BYPASS; primary and relay
  public channel-catalog manifests matched.

Public metadata and range requests used normal DNS. Full-body integrity checks
ran from the relay against the production HTTPS virtual hosts using the primary
origin address and the cache host's loopback listener. TLS hostname and
certificate verification remained enabled. This verifies package integrity and
cache readiness, without measuring Mainland China end-user throughput.

All 12 localized homepage, download and diagnostics pages matched the release
source. The ten content files were deployed with a recoverable backup at
`/opt/bobtv/backups/website114windows-20261013T180904Z`. The live API entry point
remained byte-for-byte identical, SHA-256
`6953c57c56cc7b499bb658ea20d7870239605d66c2b88929d3b72aae9df07354`.
The API, device registration, catalog data and relay runtime were preserved.

Temporary public build inputs were removed after verification; local copies
remain in `outputs/BobTV-v1.1.4`. That directory also retains machine-readable
package, GitHub, localized-content, route-state and public-delivery evidence.
The existing local Mac process kept PID 7870 throughout publication. No
installed desktop app was replaced or restarted as a publication step.

## Limits

Windows and Android physical acceptance, native Surface ARM64 and Apple Silicon
playback, Mainland China throughput and localized website browser visual QA are
not claimed. Package and mocked window tests do not replace those checks.
The local Mac kept its existing test-app PID during publication.
Automatic GitHub workflows remain manually disabled; the separate signing
workflow is manual-only and was not run for this publication. No trusted
Windows signing certificate or Apple notarization is claimed.
