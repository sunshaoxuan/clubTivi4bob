# BobTV 1.1.4

Build: `1.1.4+97`. Manual publication for Windows, macOS and Android.

## Changes

- Use the same responsive simple browser at every screen size. Player and
  browser panes have equal widths from 640 logical pixels; narrower screens
  stack vertically. Category navigation has at most three single-line levels
  with complete menus attached to their More buttons. Cards and connected EPG
  adapt to height while video retains its original aspect ratio.
- Repair macOS native fullscreen Escape and re-entry. Native Mac windows keep
  normal window level during fullscreen transitions. Native cancellation stops
  pending entry immediately. Return and double-click restore the channel screen
  while preserving a fullscreen channel window; native Escape can restore a
  normal window. Windows keeps its fullscreen topmost behavior.
- Serialize Android immersive-mode entry and exit so Back and route cleanup
  cannot restore system bars after a later fullscreen route has entered.
- Prioritize fresh permanent-retirement state for selected channel routes.
  Current-category state is queued in batches. Unconfirmed public routes are
  not played when foreground synchronization fails; the current programme is
  kept and a retry is offered. Live route-state responses bypass relay caches.
- Favorites retain all equivalent channel routes across providers. Existing
  one-route favorites expand when used, and new equivalent routes inherit
  membership. Favorites remain private to the original device; permanent
  retirement removes the endpoint from every list.
- Correct regional-ranking future cleanup and category-button width budgeting.

## Packages and updates

Windows x64/ARM64 Setup and portable ZIPs; macOS Intel/Apple Silicon DMGs and
publisher-signed update ZIPs; Android ARM32/ARM64/x64 APKs, API 24/Android 7+.
All platform packages use the same release source. Downloads and update feeds
are available from the primary website and cndrp resource relay. Video sources
remain direct connections. Publication does not restart installed clients.

Windows packages lack a trusted Authenticode certificate, so browser and
SmartScreen confirmations remain possible. Program Files installation requires
administrator consent. Mac apps are ad-hoc signed without Apple notarization.
BobTV's update publisher signatures are separate integrity checks. Android
installation and updates require operating-system confirmation.

## Validation limits

Mac fullscreen was tested on the maintainer's Intel Mac using real Escape,
button and double-click transitions. Automated tests cover all three platform
policies, responsive layouts and synchronization. Physical Windows, Android,
Surface ARM64 and Apple Silicon acceptance for this release remains pending.
Mainland China throughput has not been measured by this release validation.
See [validation](1.1.4-validation.md) for package and public-delivery results.
