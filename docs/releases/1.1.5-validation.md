# BobTV 1.1.5 validation

Target: `1.1.5+98`. Publication is in progress. This document will record final
package, signature, public-download, mirror and localized-content acceptance.
No installed application may be restarted as part of publication.

## Regression and build checks

- Full Flutter suite: 618 passed, 12 environment/opt-in skips.
- Website/API and Mac helper packaging: 174 passed.
- Download grouping and browser resource routing: seven JavaScript tests passed.
- Analysis of 12 changed source/test files: no errors or warnings; three
  pre-existing style infos remain in `player_screen.dart`.
- Fresh Universal Mac build split into Intel and Apple Silicon variants. Both
  variants passed architecture validation for all 128 native files and deep
  strict ad-hoc signing. DMG checksums and publisher-signed ZIP validation passed.
- The bundled `objective_c.framework` currently declares macOS 13.0 as its
  minimum runtime. These packages do not add older macOS compatibility.

## Existing native evidence

- Intel Mac isolated fixture: 13 passed scenarios, covering ordinary,
  maximized and native-fullscreen callers, native exit, real Escape input and
  repeated re-entry. Process exited normally. No live playback was initialized.
- Windows isolated fixture: eight geometry/style records passed, including
  ordinary/maximized callers, native-fullscreen re-entry and PiP return.
  Native caption flags and geometry were verified. Pixel-level acceptance of
  the reported white strip remains pending.
- Category popup regression covers Windows, macOS and Android themes, all 31
  province choices, short lists and small viewports with enlarged text.
- Physical Android, Surface ARM64 and Apple Silicon acceptance remain pending.

Continuous EPG discovery/refresh has only been scheduled and must not be
reported as an implemented release feature.
