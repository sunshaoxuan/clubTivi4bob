# BobTV 1.1.5

Build: `1.1.5+98`. Manual release for Windows, macOS and Android.

## Changes

- Separate native window maximization/fullscreen from video fullscreen. Video
  double-click and Return restore the original window placement and channel
  page, including ordinary, maximized and native-fullscreen callers.
- Preserve the original return snapshot through desktop PiP. Route cleanup,
  external native exits and repeated input share the owning fullscreen session.
- Remove Windows native caption style bits during video fullscreen so the
  system caption surface cannot cover the application's top-edge controls.
  Restore resize/maximize capabilities and native chrome on return.
- Remove an invalid optional-superclass termination callback on macOS. Native
  Escape, subsequent fullscreen re-entry and normal process exit are covered by
  isolated acceptance fixtures.
- Enlarge attached category popup text, buttons and spacing adaptively; fit
  short menus to their contents and keep long or scaled menus scrollable.
- Include the resumable, small-batch public-catalog classification audit source
  already running on the server. Staged results publish only after the current
  catalog has a complete audit record; manual categories remain protected.

## Packages and updates

Windows x64/ARM64 Setup and portable ZIPs; macOS Intel/Apple Silicon DMGs and
publisher-signed update ZIPs; Android ARM32/ARM64/x64 APKs, Android 7/API 24+.
Primary-site downloads and update feeds are also available through cndrp.
Video connections remain direct. Publication does not restart installed apps.

Windows packages do not have a trusted Authenticode certificate. Program Files
installation requires administrator consent. Mac packages use ad-hoc application
signing without Apple notarization. BobTV publisher update signatures provide
separate integrity checks. Android installation requires system confirmation.

## Scope and validation limits

The continuous EPG discovery, alternative-source recovery and live EPG refresh
enhancement is scheduled after classification and is not part of this release.
The bundled Objective-C dependency currently requires macOS 13.0. Broader
legacy-macOS compatibility is not implemented by this release.

Thirteen isolated native Intel Mac scenarios and eight native Windows
geometry/style scenarios passed before packaging. These fixtures do not verify
live-stream decoding or playback. Windows white-strip pixel acceptance, Android
hardware, Surface ARM64 and Apple Silicon playback remain unverified.
See [validation](1.1.5-validation.md) for final package and delivery evidence.
