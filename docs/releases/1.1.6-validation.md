# BobTV 1.1.6 validation

Target: `1.1.6+99`. Native regression and package checks passed. Public delivery
is pending. Evidence is retained under `outputs/BobTV-v1.1.6/` and
`outputs/BobTV-crash-20261017/`.

## Player lifecycle gate

- Shared Flutter suite: 694 passed, 14 skipped after the cleanup changes.
- Main, preview, warm, replacement and multi-view player constructors use the
  same tracked disposal mechanism. Desktop exit waits for native cleanup.
- Isolated Windows x64 and Intel macOS native regressions passed.
  Their test executables use a separate directory and diagnostics and do not
  open the user's catalogue, favourites or updater.
- Original macOS 1.1.5+98 evidence records native input, an AppKit mouseUp
  action and window closure immediately before Flutter teardown and an mpv
  native callback abort. Old logs cannot identify the exact close control or
  actor. No idle-close timer was found in the application close-call inventory.
- No Release is authorized by a unit-test pass alone. Fixture-target binaries
  and packages built before the cleanup changes must never be published.
- Early native iterations exposed a stopped-vsync renderer wait on macOS and
  an unreleased close veto after Windows platform exit. Both were corrected
  before the final regressions. A manually closed test window and a test-only
  hidden-last-window termination are retained as excluded iterations, with no
  long-playback pass inferred from them.
- Windows passed four native cases, including 600 seconds of continuous
  main/preview playback and 20 create/dispose cycles. Intel macOS passed
  three native cases with the same 600-second playback and 20-cycle soak,
  plus two short production-PlayerService exit cases. Every process exited
  with code 0 and zero remaining players. No new macOS crash report appeared.
- Both long runs recorded 600 main and 600 preview position changes, with
  zero player errors. RSS median growth was 2,359,296 bytes on Windows and
  45,883,392 bytes on macOS. The six production lifecycle source hashes on
  both hosts match the frozen release source.
- These tests use an original raw-video/PCM fixture, real native players and
  renderers, with muted/null audio output. They do not certify audible audio,
  H.264 hardware decoding, or indefinite unattended playback. No spontaneous
  close occurred during either final ten-minute run.
- Native evidence: `macos-regression-final/macos-qa-success.json`,
  `macos-service-r4/macos-service-qa-success.json` and
  `windows-player-qa-status.json` in the retained output directories.

## Known acceptance limits

- Shared EPG fixtures are not physical Windows, macOS or Android playback tests.
- Production EPG has no approved public programme version yet. Two real
  consecutive automatic publications and running-client hot updates are pending.
- Broader verified automatic replacement-source activation is incomplete.
- Surface ARM64, Apple Silicon and Android hardware acceptance is pending.
- The Windows white-strip visual check from 1.1.5 remains unverified.
- No installed client will be installed over, closed or restarted for release.
- Windows trusted Authenticode signing and Apple notarization are unavailable.
- macOS dependency compatibility remains macOS 13 or later.
