`outputs/BobTV-route-performance-20261017/`.

## Verified before release packaging

- The targeted playback, preview, route ranking, retired-route and UI resource
  suite passed 41 tests. Eight strengthened immediate-preview tests passed again.
- Preview ownership reuses the existing decoder and controller. The buffering
  recovery gate and scheduled-frame wait were removed. Native audio handoff and
  retirement/superseded-request guards remain.
- The scoring repair was deployed to the main API only. Six public ranking and
  eight network-profile requests across main and cndrp returned HTTP 200.
  The original check's largest relay ranking request took 4562.37 ms. A fresh
  check after the website reload passed all 14 requests, with a maximum of
  2093.11 ms. No media probes or synthetic playback reports were submitted. The
  EPG API process was not restarted.
- Before the final immediate-preview revision, 130 client tests passed,
  including two real public snapshot imports with 8,766 channels and 9,604 routes.
  The backend scoring tests passed 29 cases. These are separate overlapping runs.

## Physical acceptance limits

No installed client is replaced or restarted. New-version measured switching
latency, audible continuity, long playback, and Windows ARM64, Apple Silicon and
Android physical-device acceptance remain pending. Existing lifecycle soak
evidence from 1.1.6 is historical and does not certify the new preview path.
The other Windows machine's authorization stall has not been reproduced on that
machine. Secure-desktop UAC approval requires human/device acceptance; mocked
consent boundaries do not establish a successful real UAC interaction.
