  Application signatures, version plists, DMG integrity and publisher-signed update
  archives passed validation.

  78 native files respectively. Executable and installer versions match this release.
- Both Windows media-library hashes match the previously validated release.
  Installer fixtures passed Unicode paths, player-exit waiting, shortcut choices
  and uninstall checks. Final Setup publisher signatures passed Windows CNG checks.
- Both operating systems built from the same frozen product source and SDK versions.
  ZIP paths use portable forward slashes. All ten GitHub release asset sizes and
  SHA-256 digests match the locally validated packages.

  release. Existing player components match the prior release byte for byte.
  Trusted Authenticode signing and Apple notarization remain unavailable.
