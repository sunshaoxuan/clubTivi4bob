# BobTV 1.1.8

Build: `1.1.8+101`. Windows x64 / ARM64 and macOS Intel / Apple Silicon.
Android packages remain at 1.1.7.

- Group routes for the same service into one channel card across compatible
  domestic categories and international genre memberships.
- Deduplicate canonical stream addresses in candidate counts and alternative
  playback while preserving source records and provenance.
- Identify merge selections by channel identity. Another channel with the same
  display name stays selectable; selections are revalidated before review.
- Preserve country, region, guide, UHD, television/radio and time-shift
  distinctions. Entries without enough identifying metadata remain separate.
- Preserve Unicode channel names, including Cyrillic, Arabic and Greek.
- Keep favorites, manual settings, explicit merges and exact EPG bindings.

A full installed-database backup replay covered 22,050 source records and reduced
repeated display identities in 1,051 name groups. This does not establish that
every same-name entry is the same service or that every candidate is playable.

No installed application is replaced or restarted by publication. Windows
packages use the existing publisher-verified updater and macOS update archives
retain BobTV publisher signatures. Trusted Authenticode signing and Apple
notarization remain unavailable, as in the previous release.
