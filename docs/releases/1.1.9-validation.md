# BobTV 1.1.9 release validation

Product version: `1.1.9+102`.
Frozen product source: `118fe7775cae1405c690005248318c033588b90d`.
Reviewed website content: `52c846eb7b82af9b732fa556fbff7b909f9bbd7b`.
Platforms: Windows x64 / ARM64 and macOS Intel / Apple Silicon.
Android packages and update feeds remain at `1.1.7+100`.

## Client and content checks

- The isolated release passed 783 Flutter tests with 20 environment-gated skips.
- Website/network checks passed 20 tests; download CPU-menu checks passed 3.
- Actual production player routes were tested at 984 by 611 and 800 by 500,
  with playing and paused simulated decoders at volume zero. Entering and
  leaving window playback kept the current player, controller and position.
- Unit checks cover pin verification/rollback, rapid requests, fullscreen and
  PiP presentation locks, window geometry, external native exit and Esc return.
- Static analysis found no compile errors. Two informational asynchronous
  BuildContext diagnostics remain confined to the own-window QA script.

## Native packages and window checks

- Both macOS bundles passed architecture, application signature, version and
  DMG integrity checks. Each architecture contains 128 validated native files.
- A separate macOS Intel window fixture passed pin/unpin and two fullscreen
  round trips, restoring geometry and the explicit pin preference each time.
  It opened no media, produced no audio, and did not operate installed apps.
- Windows x64 production compilation and isolated installer fixtures passed
  Unicode paths, wait-for-exit, shortcut choices and uninstall checks.
- Windows x64 and ARM64 packages passed complete PE/AOT checks for 82 and 78
  native files respectively. App/Setup versions match, all four raw transfer
  hashes match the build host, ZIP paths are normalized, and both media-library
  hashes match 1.1.8. Actual Setup hashes and publisher signatures passed Windows
  CNG verification. All four update packages passed archive validation.
- The Windows x64 own-window fixture passed pin/unpin and two fullscreen round
  trips with the explicit pin choice and geometry restored. Its limited task
  initially encountered the existing pwsh RUNASADMIN preference. Using the
  ordinary Windows PowerShell launcher resolved that without changing the
  preference or elevation policy. The fixture task was removed afterward.

## Publication and delivery

- Public release: https://github.com/sunshaoxuan/clubTivi4bob/releases/tag/v1.1.9
- The source tag and all ten public GitHub asset sizes/digests match the frozen
  product source and locally validated release packages.
- Mirror invocation `04a72682fce442ddabc992c624b220c6` completed successfully with
  exit status zero and `Published 143 mirrored releases` in its own journal.
- The main public endpoint passed four desktop latest/historical feed checks,
  six manual-download range checks and twelve complete-body SHA-256 checks.
- The cndrp public endpoint passed four desktop feeds and six manual ranges.
  Its cache-host HTTPS observer passed all twelve complete-body hashes while
  retaining hostname and certificate validation. This verifies cache delivery
  integrity; external regional throughput remains a separate observation.
- The bounded external Mac-to-cndrp observer confirmed the four feeds and six
  manual ranges but reached its 180-second deadline without completing a full
  body. Its partial receipt is retained. External full-body delivery and a
  physical mainland-network throughput measurement remain unverified.
- Initial relay range probes encountered transient 502 responses during the
  website service's content switch. Subsequent range checks and cache-host
  full-body checks succeeded. Relay configuration and security settings were
  not modified or restarted to obtain those results.
- Seven website content files were replaced with a recoverable backup at
  `/opt/bobtv/backups/website119-20261022T162321Z`. Deployed hashes match reviewed
  source, and twelve strict template renders passed across Simplified Chinese,
  Traditional Chinese, English and Japanese. Public HTML/browser page inspection
  was not performed because browser origin access is denied.
- Server Python runtime hashes and the EPG API PID were preserved. Existing
  EPG timers continued independently. Installed desktop apps were not operated,
  replaced, installed over or restarted by this workflow.

## Explicit verification limits

- No physical Windows ARM64 or Apple Silicon playback acceptance was performed.
- Native window fixtures open no media. UI presentation reuse is asserted;
  audible continuity and real-stream playback acceptance remain unperformed.
- Browser visual checks are unavailable because a saved browser permission
  denies access. This restriction was preserved without alternate-browser or
  security-setting workarounds. Deployed-file hashes and local template renders
  establish the content check's narrower scope.
- Trusted Windows Authenticode signing and Apple notarization remain unavailable.
- Separate radio, native-player, updater and EPG server changes in
  the working checkout remain outside this frozen release. No installed app or
  EPG service is replaced or restarted by this publication workflow.
