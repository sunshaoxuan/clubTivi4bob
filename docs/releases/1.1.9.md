# BobTV 1.1.9

Build: `1.1.9+102`. Windows x64 / ARM64 and macOS Intel / Apple Silicon.
Android packages remain at 1.1.7.

- Add a window-filling playback button next to the existing fullscreen control.
  It uses the app's client area while keeping native window borders and bounds.
- Reuse the current player, active route and paused state when entering window
  playback. Escape returns to the channel browser without reopening the stream.
- Add an always-on-top push pin to the preview footer and window player. Click
  again to unpin. The choice is retained during the current app run.
- Preserve the pin choice and window geometry through native fullscreen and
  picture-in-picture transitions. Keep the controls usable in narrow windows.
- Preserve favorites, manual EPG bindings, private sources and offline caches.

No installed application is replaced or restarted by publication. Tests use
muted or simulated playback without changing system volume. Trusted Windows
Authenticode signing and Apple notarization remain unavailable; BobTV publisher
signatures continue to protect the update packages.
