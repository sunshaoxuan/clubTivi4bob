# BobTV 1.3.0

版本：1.3.0+0

- 自动节目单与字幕：有可确认 EPG 的频道共用自动检索流程，按当前节目寻找并缓存字幕。
- 七种语言偏好按指定语种、英文、无字幕选择；缺少节目资料或资源时显示明确状态。
- 客户端复用播放音频识别台词，服务器负责检索、缓存和对齐，不持续拉取视频流。
- 广告期间暂停电影字幕，正片恢复后用新台词确认位置再显示。字幕跟随视频窗口与画中画位置。
- 多字幕源检索覆盖完整匹配列表，各语种保留自身分句；按整片时间证据配对字幕版本，并校核简繁体内容。
- 官网新增自动字幕专区与广告暂停、恢复流程示意，七种语言同步更新。
- Windows、macOS、Android 七个平台同步发布。显示编译计数重新从 0 开始；Android 安装版本码保持递增以兼容已有安装。

字幕取决于已确认的节目身份、可用资源及版本匹配。当前语音重对齐支持英文音轨。
