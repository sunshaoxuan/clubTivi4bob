# BobTV 1.3.0

版本 1.3.0+0

- 对于能从节目单确认当前节目的频道，BobTV 会从多个已接入的字幕来源自动检索并缓存文件。换台或换节目后，字幕会随节目更新。
- 播放中打开字幕菜单，可随时调整语言偏好、切换版本或关闭字幕。支持七种语言设置，每种语言最多列出三个去重后的候选。自动选择优先使用指定语种，其次是英文。两种都没有可用版本时，播放器会显示状态提示。
- 各字幕版本保留自己的时间线。切换后，播放器会在确认字幕版本与正片匹配并同步后显示字幕。
- 客户端从播放音频识别台词，服务器负责检索、缓存和对齐。广告期间暂停正片字幕，正片恢复后用新的台词确认位置。字幕跟随视频窗口与画中画位置。
- 官网新增自动字幕专区与广告暂停、恢复流程示意，七种语言同步更新。
- Windows、macOS 和 Android 七个平台统一使用 1.3.0+0。显示编译计数从 0 开始，Android 安装版本码继续递增。

字幕可用性取决于节目单、已接入来源的文件和正片版本。当前语音重新对齐支持英文音轨。
