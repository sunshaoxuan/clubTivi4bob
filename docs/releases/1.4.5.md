# BobTV 1.4.5

适用于 Windows x64/ARM64 和 macOS Intel/Apple Silicon。

- 修复同一电视重复 DLNA 投放和换台的会话停止与重连流程。
- 补充局域网媒体中继的 HEAD 与 Range 请求支持，保留原始媒体字节。
- 增加 LG WebOS 视频 v2 播放队列兼容，修正设备功能标记解析，等待接收端播放状态后确认启动。
- 改进 AirPlay 临时验证码取消、重试及凭据复用；固定密码视频接收端会提前提示当前限制。
- 更新桌面自动更新组件的校验及交接流程。

本次更新不包含移动版。LG 电视实机兼容及具体频道的画质、流畅度仍需复测，固定 AirPlay 密码视频尚未支持。
