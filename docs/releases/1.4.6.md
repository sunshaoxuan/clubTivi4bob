# BobTV 1.4.6

2026-11-26 更正：Mac 自动更新包内的进度辅助程序版本信息有误，可能在下载完成后被旧版更新器拒绝。请升级至 1.4.7，该版本已通过 1.4.5 更新器的完整安装验证。

适用于 Windows x64/ARM64、macOS Intel/Apple Silicon 和 Android ARM32/ARM64/x64。

- 改进启动时长时间停留在频道加载画面的问题：当前分类就绪后先显示频道界面，随后继续准备线路索引。
- 减少频道名称、身份及收藏整理中的重复计算。
- 打开投屏界面即开始记录关键诊断，覆盖设备搜索、配对、连接、播放命令、返回码、取流、中转和耗时。
- 开启诊断同步后，投屏事件触发增量上传；上传、中继与下载采用 gzip 压缩并保留完整性校验、容量限制和失败重试。
- 日志包含匿名终端指纹、安装实例编号和投屏会话编号，便于区分不同设备与操作。影音内容、完整播放地址和配对凭证不会写入新增投屏诊断。

电视实机的频道兼容性仍需结合新增诊断分析。本版未新增通用屏幕镜像或视频实时转码。iOS 发布渠道保持现状。
