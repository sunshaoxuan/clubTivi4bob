## Reproduction and repair

The 1.4.6 Mac archives passed file integrity checks but embedded `BobTVUpdateProgress.app` with version `1.0+1`. The 1.4.5 update worker requires this observer's native version to match the target application, so it exited with code 7 before installation. An isolated run using the installed 1.4.5 worker and the original Intel release archive reproduced the failure.

`prepare_release_variants.py` now copies both version fields from the main bundle before signing. The signed-package builder checks observer identity and version. The seven-platform alignment gate independently checks both bundle plists inside each Mac archive. Negative regression cases cover stale observer semantic versions and native build numbers. The enhanced gate rejects both original 1.4.6 Mac archives.
