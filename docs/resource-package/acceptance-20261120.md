# 资源包 v1 验收记录

日期：2026-11-20。本机 Intel Mac、Xcode iOS 26.2 官方模拟器。本地开发构建，应用版本未变更。

## 完成范围

- BobTV 自定义 UTF-8 JSON `.bobtv` 数据协议，严格版本、字段、类型、引用和容量校验。
- URL 下载、HTTP gzip、文件导入入口、数量与订阅主机预览、确认后原子导入。
- 分类、频道名称、稳定频道/线路 ID、多线路、服务器台标地址、XMLTV 地址及显式频道绑定。
- 订阅每 15 分钟前台检查、手动刷新、失败保留旧快照、删除中刷新保护。
- 线路地址改变时保留本地收藏；撤回收藏线路留下不可播放的引用；移除 EPG 来源停用更新；退订清理所属资料。
- iOS 新数据库没有频道、来源或提前下载的节目表，无默认公共目录和免费来源推荐。桌面现有分发逻辑保持原模式，其他构建可显式使用 `BOBTV_USER_SOURCES_ONLY=true`。
- 逐条手工加源，复用名称分类识别、台标解析和 EPG 刷新，重复手工地址去重。

## 验证边界

本轮完成协议与客户端接入，服务器使用本机自有测试数据，尚未发布生产资源包或上传应用商店。文件选择器入口已编译，文件内容经解析器与命令行工具验证；模拟器端到端使用 URL 导入，没有把系统文件选择器计为已实测流程。

字幕下载与对齐继续使用现有播放链路，没有增加资源包专用字幕服务器接口。自有测试节目没有匹配字幕，画面显示缺少字幕所需节目信息，因此本轮不计入真实字幕下载、显示或对齐成功。iOS 原生识别的既有未完成项继续见 `docs/mobile-planning-20261120/ios-native-adaptation.md`。
