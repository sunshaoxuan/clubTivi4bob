# Windows 全频道 EPG 修复验证

目标主机为 SUNSX-PC。原安装版本为 1.1.10+103。此前仅在本地 Mac 安装的 EPG 修复没有进入该 Windows 安装。

## 已确认的问题

- XMLTV 中单条非法节目时间会导致整份节目表导入失败，旧缓存随后过期。
- 公共频道缺少本地节目源的有效绑定，卡片只有取得非空节目列表才展开，失败或缺失数据没有可见提示。
- 早期补丁的本地匹配限制于中国公共频道和两个预设源，覆盖范围不足。
- 卡片复用列表中的 EPG 标识，映射更新后点击仍可能读到旧标识。
- 默认源初始化会移除旧预设源，导致已有跨地区节目源丢失。

## 通用修复

`LocalEpgBinding` 对所有播放列表、国家、地区和启用的 XMLTV 源使用同一套匹配逻辑。优先使用明确的 tvg-id，其次使用无歧义的标准化名称；保留 +1、地区、4K 等身份差异。纯数字 ID 必须有名称证据。存在冲突时不自动填入相似台的节目表。手工、锁定和服务端精确映射保留原有优先级。

每次选中卡片都从数据库解析最新映射。快速切换频道时丢弃先前请求的迟到结果。卡片统一显示节目列表、正在加载、读取失败或暂无节目表状态，读取失败后再次点击可重试。

每个源按设置的刷新周期检查；启动时即使缓存未到下载时间也会重新协调映射。保留已配置的自定义及旧版节目源，仅在没有 XMLTV 配置时初始化默认源。

XMLTV 解析跳过单条异常节目，其余有效记录继续事务导入。全份无有效未来节目时保留旧缓存并报告失败。
