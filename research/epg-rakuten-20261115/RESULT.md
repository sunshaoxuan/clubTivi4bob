## 范围与持续探索

目标是当前公开目录的全部 9,098 个频道。Action Movies 仅用于完整链路验收，覆盖数字始终按实际频道身份与节目数据计算。队列每轮重新读取当前目录，按国家轮转，并交替处理未探索频道和到期重试频道。定时任务每轮最多五项，保留时间预算与上游退避。

生产观察中，16 个已审映射受保护，1,777 个未完成频道已进入研究队列，7,305 个频道尚待逐项准入。三项互斥合计 9,098，尚未准入也属于全量目标，不能记为已探索。后续目录变化会重新计算。这些数字是当时快照，不能用作长期固定统计。

每日 500 次请求限制已从生产执行路径删除，旧的本地配额等待状态只迁移一次。最近 24 小时已实际记录 512 次请求，最近一小时 37 次。滚动一小时 60 次的负载保护和上游 429、鉴权错误退避保留，审计历史保留。部署后已观察到不同国家的真实搜索与 HTTP 读取，定时任务仍在运行。

## 官方适配器与实际证据

官方入口：https://www.rakuten.tv/uk/live_channels/action-rakuten-tv

实际接口：https://gizmo.rakuten.tv/v3/live_channels

两天本地日历窗口使用明确带时区的 ISO 参数 epg_starts_at、epg_ends_at。必须读取完整分页，并校验 market_code、service ID、总页数、去重与重叠节目。每页记录响应哈希与抓取时间。无 live_programs 字段的 HTTP 200 不算节目数据。电影条目的 is_live=false 不会导致当前节目被丢弃。

英国市场本轮八页返回 193 个来源频道、11,980 条有效节目。这些属于来源可用性，只有两个 BobTV 频道完成映射：Action Movies，英国 service 6065；Romance Movies，英国 service 6194。两者的英国线路、明确服务编号、官方当前节目与 HLS 电影元数据已分别核对。Romance 的后续观察遇到广告，保留其较早的有效身份证据，未把广告当作节目。

其余五个当前目录候选为 Drama Movies、Top Movies、Comedy Movies、Reality、Family，继续保留国别或线路语境待审。名称相近无法证明版本一致。映射在后续入库及发布时仍会重新检查当前所有线路，出现混合市场或不同 service 会暂停使用。未修改这些待审频道的分类。

只缓存与发布节目名称、时间、节目与影片标识等事实数据，不发布影片简介、剧情或海报。来源授权范围、频道身份与实际节目分开记录。

## 深入探索的通用能力

节目候选使用真实 GET，读取响应体并检查 JSON 或 XMLTV 日期区间。历史 HEAD 空响应的成功缓存不能继续代替读取。对于 JavaScript 页面或空节目响应，记录需要追查脚本、公开 API、日期格式、市场、时区和分页的后续事项，未解决时保持待审。

带日期、频道和分页的公开节目查询参数现已受控支持，身份页面及通用来源注册的无查询参数规则保持不变；拒绝未知、凭据、重复和控制字符参数。一次真实官方分页 GET 读取 559,379 字节，检测到 677 个带有效时间区间的对象，当前及未来时间对象分别为 18、448。这是结构检查结果，可能包含嵌套重复对象，不属于正式节目覆盖数量。

## 发布与客户端验收

两个公开节点的 manifest、压缩快照字节及 SHA-256 一致。正式发布当前与未来 EPG 共 16 个频道、959 条节目，新增两项映射，原有映射逐行比较保持不变。Action Movies 与 Romance 的私有事实数据分别含 28、27 条节目，公共快照会按有效时间窗口筛选。

当前 1.1.21 macOS Intel 客户端已实际显示 Action Movies 当前、下一档及随后节目：Saints and Soldiers - Battle of the Tanks、Adrift、Superfast!。当前时间显示为日本本地 00:26 至 02:16。现有热更新机制接收服务器数据，本轮无需发布客户端二进制。

Python EPG 回归 1,109 项通过。客户端核心测试 70 项通过、2 项因缺少其要求的历史实际抓取文件而跳过；使用双节点实际快照的导入、幂等、映射与离线保留测试另行通过。真实快照含多线路频道，因此客户端回放测试按线路数核对映射，不再假设每个频道恰好一条线路。

EPG 目录已接入，全部频道的 EPG 仍未完成。节目时段不能直接作为电影字幕进度；本轮没有重新进行广告插播后的字幕恢复实测。
