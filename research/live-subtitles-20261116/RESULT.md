# 2026-11-16 生产 EPG 与直播字幕实测

本文时间采用日本时间。新增覆盖以生产发布快照的频道集合变化计算，排队、候选、历史节目与恢复已有映射均单独记录。

## 已接入

外部字幕检索与本地实时语音校准服务已部署至生产独立服务，客户端源码默认连接生产接口。首批外部字幕范围为经过身份复核的 Action Movies 英国版，Rakuten service 6065。其他频道继续使用原有内嵌字幕选择。七种语言为 en、zh-CN、zh-TW、ja、fr、es、ko，按指定语种、英文、无字幕选择。简繁中文分别处理。

EPG 提供具体播出事件与电影身份，服务另取官方电影年份并检索现有字幕文件。英语音轨通过 tiny.en 识别用于校准，识别结果不会作为字幕生成或翻译。各语种字幕需要与校准参考共享经过核验的字幕时钟。外部提供者译文质量尚未人工评审。

广告或身份不明时停止影片字幕。同一已验证素材恢复后，只有原始 PTS 延续误差在 160 毫秒内才允许复用校准；时钟重置、素材变化或语音复核偏差超限将重新获取语音锁定。广告期间 ASR 的迟到结果受代际与素材检查约束。播放器按自身解码位置选择字幕，缓冲或暂停时隐藏。

客户端为开发版原生 Flutter 测试程序，使用实际 PlayerService、ManagedPlayer、BobtvVideo 与生产服务，自动切换三个视频尺寸和位置。已安装正式客户端未替换，本轮未发布七平台安装包。当前窗口截图读取失败，最近一轮显示状态通过原生控件数据记录；不等同于七平台目视验收。

## 真实直播过程

使用当前直播流，未回放历史媒体或预置字幕决定。字幕文件下载、语音锁定、插播判断、恢复与原生客户端观察全部自动运行。

前两次完成的真实插播均为 150 秒。第一次广告期间 3,138 次采样没有影片字幕，服务观察恢复为 1.819 秒，语音留出样本最大误差 0.447 秒，但播放缓冲约 6.8 秒。第二次广告期间 4,125 次采样没有影片字幕，服务观察恢复为 1.758 秒，语音参考误差中位数 0.286 秒、最大 0.530 秒，但播放累计缓冲约 56.25 秒。这两轮整体播放验收失败。

独立分片复用导致的 TS 连续计数错误已修正。第二轮 150 个广告分片的准备延迟中位数约 0.325 秒，最大约 1.211 秒。随后把连续的一秒分片组合为约六秒的传输分片，保留连续时间戳，遇到广告、素材、断流和不连续边界即结束组合，播放序列独立连续编号。真实六秒广告样本可解析出 H.264 与 AAC，无损坏告警。

直播换片也实际发生：官方 EPG 从 The Engineer (2023) 切换到 Tom Clancy's Without Remorse (2021)。曾因字幕文件名省略所有格撇号导致检索失败，现已修正片名标点归一化，保留完整片名词序与年份条件。修正后实际读取到包含简体中文的现有字幕文件。失败的换片准备轮次未计入完整验收。

最终实测使用未改动的原生客户端二进制与生产字幕服务 `0745c9b`。2026-11-16 日本时间 10:02:16 观察到广告，随后正片恢复，整个过程无人修改字幕时钟、重启播放器或手动定位。

三个实际显示样本分别比 tiny.en 识别的词首参考提前约 0.335、0.375、0.010 秒。语音参考来自恢复后新采集的直播音频，未参与重新拟合此次恢复偏移。服务复用经过连续性验证的 PTS 快速恢复，此后用新语音样本复核。首条中文字幕在返回后 15.379 秒显示，其文件对应的计划时间为返回后 15.377 秒，两者采样差约 0.002 秒。原生状态采样为 50 毫秒，后端解码位置通知约为 200 毫秒，因此该数值不能解读为两毫秒的人工视听同步精度。

最终独立审计判定通过，前三条新语音样本均实际经过客户端并显示为 zh-CN。生产结束核查确认服务仍运行同一版本、所有部署文件校验一致、系统服务自动重启次数为零。此次通过仅覆盖这一频道、这一轮广告与原生开发客户端，其他平台及其他广告模式仍需各自实测。

新增七台为 Pluto TV Movies、Pluto TV History、MTV Pluto TV、MTV Catfish、Comedy Central Pluto TV、FBI Files 与 Los Asesinatos de Midsomer。四台和 Comedy Central 为德国版，FBI Files 为英国版，Midsomer 为西班牙版。后三台在正式分类流程中纠正了原来的美国归属，频道 ID、播放地址、路线 ID 与 EPG 标识保留，路线元数据版本按规则递增。其他已审批映射保持不变。

Pluto 列表接口返回空列表，单频道详情接口默认只有元数据。深入验证后确认，单频道接口加入明确的 start、stop 参数才返回实际 timelines。新增适配器读取实际节目时间、事件和剧集 ID，检查明确时区、重叠节目、当前与未来覆盖，绑定已核实的精确播放 feed ID，并接入生产采集、发布与客户端节目身份上下文。HTTP 429 的 Retry-After 秒数和 HTTP 日期均保留退避下限。

本轮实际探查 22 条 Pluto 频道路线，14 条读到节目正文，最终发布七条。其余七条节目可读取但播出地区证据不足，进一步读取官方元数据仍未取得地区字段；官方网页探查出现 404 或地区不可用跳转，继续待审。另八个旧 feed ID 的实际节目请求返回 404，需要重新查明路线身份。Frikanalen 官方文档给出了 XMLTV 和 TV-Anytime 接口，本机与生产机实际访问均遇到根域证书域名不匹配，www 域名同路径则返回 404，未导入任何推测节目。

两处生产节点最终快照经压缩内容 SHA-256 核验一致。当前基准为 9,093 台目录频道，28 台具有当前与未来节目，1,382 条节目记录。覆盖仍低，以上新增均为本轮首次发布，恢复数量为零。每日 500 次探索限制已移除；失败、认证与 429 的退避下限继续执行。五项 EPG 定时任务及字幕服务已检查为 active。
