可验证的源码构建

仅在 GitHub 标准托管 Windows 环境中，从本项目 main 分支手动触发构建。推送、定时任务和自动发布均不触发签名。Windows x64 与 ARM64 候选构建、打包验证已通过，此次验证未上传二进制成果物。

每次签名人工批准

先审批和签署 BobTV.exe，再生成和签 Setup，验证信任链、时间戳、版本与发布者后才准备新版本发布。

02 / MAINTAINER

维护与审核责任

作者、代码审核者和签名批准人：sunshaoxuan。账户必须启用多因素验证，生产签名不得绕过人工批准。

签名范围

本项目签署 BobTV.exe 和 BobTV Setup。第三方 DLL、微软运行库及辅助程序保留自身许可，不冒用本项目签名。免费签名候选包不附带旧版可选 ProcDump 工具，保留 BobTV 原生 Windows 转储功能。

密钥与更新

SignPath 提交密钥仅作为受限密钥保存。BobTV 自有更新签章的私钥留在维护者设备，不上传仓库或构建服务器。正式签名后重新生成校验值及更新签章，已发布版本不被覆盖。

04 / ENGLISH

Policy summary

Author, reviewer and signing approver: sunshaoxuan. Accounts must use MFA; production signing requests require the maintainer's manual approval.

Origin and verification

Builds use standard GitHub-hosted runners from this repository's main branch. Original app and Setup are uploaded before signing. Name, version, CPU, Windows trust chain, timestamp and approved publisher are checked. Unsigned and test-signed candidates are not public releases.

Privacy and third parties

Only BobTV's app and Setup are signed. Third-party components retain their licenses; proprietary dump helpers are excluded from signing candidates. See the privacy policy and repository policy. The application was not approved; existing Windows packages have no trusted Authenticode signature.
