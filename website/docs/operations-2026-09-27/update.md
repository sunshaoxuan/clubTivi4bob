# BobTV site update, 2026-09-27

Repository note (2026-09-28): this is a historical deployment record. The maintained site and API source moved from `server-admin-app/sites/bobtv` to `clubTivi4bob/website`.

The product eyebrow now says "Windows desktop TV player" without asserting Windows 10 compatibility. The BobTV upstream README currently lists Windows 11 as a build requirement; Windows 10 needs a client-side compatibility test before being advertised. The three feature descriptions were shortened to avoid single-character final lines.

The hero image was initially captured from the actual BobTV v0.9.1-bob.9 simplified-mode window. The ZIP came from the site's own mirror and matched SHA-256 `5dc081163ea3b2bc6fe5286306ea916c5c08dc0d5d70df5cf2dc8a3ceb7cc817`. The user subsequently supplied a better crop of the BobTV simplified-mode interface with live playback and channel listings; that image replaced the empty-state capture. No BobTV client source code was modified.

The source report UI was removed. The public site now has separate product, download, and diagnostic pages; `/reports` returns 404. Clients can read the reviewed catalog and submit playback observations or explicitly consented candidates through `/api/v1/sources`, `/api/v1/source-reports`, and `/api/v1/source-candidates`. There is no public contribution summary or candidate read endpoint. Client-generated, stable 64-character lowercase hexadecimal fingerprints are hashed again before storage; raw MAC addresses are not accepted. The private candidate database records IP, coarse device class, and a country code only when provided by a trusted Cloudflare edge, and expires records after 14 days. The candidate migration ran twice as `bobtv` before deployment, the existing report migration remained idempotent, `bobtv.service` became active, and `bobtv-prune.service` completed with `Result=success`. A copy of the previous site is retained on the server at `/opt/bobtv/site-pre-api-only-20260927` for rollback. The reviewed `sources.json` catalog remains empty until a publicly distributable playable URL is supplied and verified. No released client currently calls these APIs; `sites/bobtv/SOURCE_INTEGRATION_PROMPT.md` is the client-side handoff.

## Release-led site redesign

The product, download, and diagnostic pages were rebuilt as separate pages under a consistent light interface. Homepage copy was checked against the published `v0.9.1-bob.9`, `v0.8.4-bob.8`, and `v0.8.0-bob.7` release notes on 2026-09-27 at `https://github.com/sunshaoxuan/clubTivi4bob/releases`. This source is used for editorial verification and is not linked from the public download page. The product page now explains preview-before-switch, channel organization, route feedback and recovery, fullscreen, radio, Mac AirPlay, and the portable package. The download page keeps all links on this host and lists release-specific changes; the diagnostic page retains the existing filtered manual upload flow. No BobTV client code or reporting API behavior changed. The reviewed source catalog remains empty and third-party playback is not guaranteed.

The site was deployed with a backup of the previous HTML and CSS under `/opt/bobtv/site-redesign-backup-20260927`.
