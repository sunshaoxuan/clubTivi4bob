安装说明

根据操作系统和处理器选择安装包。

01

Windows

运行 Setup 可选择安装位置和桌面图标。默认位置为 Program Files 下的 BoB\BoBTV，需要管理员授权。ZIP 便携包请完整解压后运行 BobTV.exe。个人频道和收藏保存在用户数据目录。

02

macOS

打开本站提供的 DMG，将 BobTV.app 拖到 Applications。如需退出后自动更新，可安装到个人目录下可写的 Applications 文件夹。请勿长期从只读磁盘映像运行。本版应用采用 ad-hoc 签名，没有 Apple Developer ID 签名与公证；自动更新 ZIP 另有 BobTV 发布者签名校验。首次打开仍可能需要手动允许。关闭的功能不读取其钥匙串凭据，拒绝授权后暂停自动访问，等待主动恢复。

03

后续更新

客户端在启动时、每六小时及返回前台时检查更新。Windows 安装版在应用内下载并校验 Setup，点击安装后请求管理员授权，再显示安装进度；取消授权可继续使用旧版。旧安装版需先安装一次本版 Setup。便携 Windows 与可写位置的 Mac 版退出后更新，连续三次启动失败会尝试回退。受保护位置的 Mac 版需手动替换。未有受信任代码签名，Edge 首次下载的安全提示仍可能出现。

04

Android

Android 7 及以上可安装 APK。先选 ARM64；仅支持 32 位应用的旧设备选 ARM32。x64 包用于相应设备或模拟器。画面按原始比例显示，竖屏与横屏自动调整布局。首次更新可能需要允许 BobTV 安装应用，然后在系统窗口确认。

02

首次启动与频道同步

BobTV 从 BobTV 网站同步频道和完整分类层级，自动比较主站与 cndrp 资源节点。来源发现与 AI 分类在服务器执行，视频直连节目源。客户端只按需检查当前频道线路。

01

初始目录

先显示本机或随包频道，再获取已分类和验证的公共清单。频道数量会随来源维护变化。

02

同步状态

同步失败后会按间隔自动重试，避免状态快速反复切换。待重试时，本机修改仍已保存；不需要反复点击。

03

公共与个人

公共分类、评分、淘汰和线路转移跨设备同步，已淘汰线路不会因其他设备播放成功恢复。收藏私有备份仅原设备可取回，历史和私人订阅保持本机独立。
