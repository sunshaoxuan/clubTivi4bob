INSTALL NOTES

安装很简单。

选对设备，下载后即可开始使用。

01

Windows

下载 ZIP，完整解压 BobTV 文件夹，再运行 BobTV.exe。旧版用户需手动安装此版一次，之后可使用自动更新。

02

macOS

按芯片选择 DMG。打开后，把 BobTV.app 拖入当前用户可写的 Applications 文件夹。

03

后续更新

应用会检查网站上的新版本。下载完成并退出应用后自动安装，前提是安装位置允许当前用户写入。
