INSTALL NOTES

安装很简单。

选对设备，下载后即可开始使用。

01

Windows

下载 ZIP，完整解压 BobTV 文件夹，再运行 BobTV.exe。受旧更新器故障影响的版本需手动安装一次；0.9.1+73 及之后的版本可使用新版更新流程。

02

macOS

按芯片选择 DMG，把 BobTV.app 拖入个人目录下可写的 Applications 文件夹，再从该位置启动。请勿长期从只读磁盘映像运行，自动安装需要写入权限。

03

后续更新

启动时及每六小时检查本站。下载过程中显示进度，通过校验后才显示可安装；退出后显示下载、备份、安装和完成状态。连续三次启动失败会尝试回退并跳过该版本。

FIRST LAUNCH

频道，也会一起准备好。

从 0.9.1+76 开始，公共频道的持续维护形成完整同步流程。

01

首次打开

先显示本机或随包频道目录，再从本站获取已经分类和验证的公共清单。频道数量随来源维护变化，无需自己逐条添加。

02

查看同步状态

频道列表旁显示同步进度。待重试表示网络或服务暂时不可用，本机修改仍已保存，之后自动重试；不需要反复点击。

03

公共与个人

公共线路的分类、评分及淘汰记录跨设备同步。收藏、历史及私人订阅保持本机独立，切换电脑不会自动复制这些个人数据。
