INSTALL NOTES

安装很简单。

选对设备，下载后即可开始使用。

01

Windows

提供 Setup 的版本可运行安装程序，选择安装位置及桌面图标；默认位置为 Program Files 下的 BoB\BoBTV。安装时需要管理员授权。ZIP 便携包仍可完整解压后运行 BobTV.exe，个人频道和收藏保存在用户数据目录。

02

macOS

按芯片选择 DMG，将 BobTV.app 拖到安装窗口的 Applications 图标，再从应用程序启动。若需要静默更新，可放到个人目录下可写的 Applications 文件夹。请勿长期从只读磁盘映像运行。本版未取得 Apple Developer ID 签名与公证，系统可能要求手动允许打开。

03

后续更新

1.0.2 启动时及每六小时检查本站，返回前台时最多每十五分钟再检查一次。检查中立即显示转圈，结果会显示已是最新版、连接失败或需要授权升级。Windows Setup 安装版发现更新后，请下载新 Setup 并以管理员权限安装。Windows 便携版及安装在可写位置的 Mac 版支持后台下载、校验及退出后安装，并显示更新进度；连续三次启动失败会尝试回退。Mac 安装在受保护位置时需手动替换。

01

首次打开

先显示本机或随包频道目录，再从本站获取已经分类和验证的公共清单。频道数量随来源维护变化，无需自己逐条添加。

02

查看同步状态

频道列表旁显示同步进度。待重试表示网络或服务暂时不可用，本机修改仍已保存，之后自动重试；不需要反复点击。

03

公共与个人

公共线路的分类、评分及淘汰记录跨设备同步。收藏、历史及私人订阅保持本机独立，切换电脑不会自动复制这些个人数据。
