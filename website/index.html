BOBTV / 简洁模式实际运行画面

01 / 选台

先看一眼，再决定切换。

当前节目继续播放。点选另一频道时，频道卡片会静音预览；预览准备好后再次点选，才切到主播放器。需要立即切换时也可双击。

01

静音预览

候选频道先在卡片中准备，减少来回切台对当前画面的干扰。

02

频道与节目时间轴

点选反馈立即呈现，选中频道与近期节目共用清晰轮廓，当前节目和后续安排一目了然。

03

收藏与音量

频道和主播放器共用菜单，可一键加入收藏；简洁界面提供鼠标可用的音量控制。

02 / 浏览

频道有序，找到想看的更快。

按地区组织电视目录，并让央视、卫视、地方台、国际频道与电台各归其位。频道排序稳定，CCTV-5 与 CCTV-5+ 保持独立。

央视频道CCTV1 至 CCTV17 按数字排序，4K、8K 与 CGTN 接续排列
国家与地区中国按央视及地方地区展开；其他国家和地区可钉选到主导航，分类支持继续细分
分类与频道合并右键可变更分类及子分类，也可跨分类合并多个频道，选择统一名称，线路去重后在后台同步

03 / 公共频道同步

一份频道清单，持续一起维护。

Windows 与 Mac 共用网站上的公共频道、分类和线路记录。新安装先显示本机或随包目录，再在后台获取经过验证的公共清单，无需等每条线路重新扫描。

01 / 初始化

打开后逐步就绪

读取最新分类、节目单映射和候选线路。列表旁显示同步中、已同步或待重试，播放区域保持清楚。

02 / 持续维护

修改留在后台完成

公共频道的增删、分类修改、线路加减权及淘汰会持久保存并异步上传。离线时保留修改，联网后自动重试。

03 / 跨设备

淘汰结果持续生效

客户端每分钟检查清单版本。重复上报不会重复计分，旧清单不会恢复已删除或淘汰的线路，新来源仍需网站验证。

共用的是公共电视目录与线路记录。收藏、播放历史、私人订阅及账号信息留在本机；同步成功也不代表第三方线路始终可播。

04 / 播放线路

同一个频道，优先选择更可靠的线路。

BobTV 将同一频道的可用线路归组，结合本机连接表现与公共评分排序。播放成功会加权，失败、卡顿和手动跳过会减权；污染线路可在右键菜单中淘汰。

识别区分频道与线路

例如 CCTV-5 与 CCTV-5+ 保持独立，避免错误的同名归组。

选择参考播放健康

真正解码播放的线路获得正向记录，失效和手动跳过会影响排序。

恢复准备替代线路

当当前线路中断时尝试切换，候选无法产生实际播放时恢复原线路。

线路状态取决于源提供方及网络环境，不能保证所有频道始终可播放。

服务器链路

来源发现与 AI 在服务器执行。

客户端从 BobTV 网站接收频道、分类和线路结果。节目播放、节目单及台标通过 HTTPS 服务链路获取，客户端不直接访问 GitHub 或 AI 提供方。

01

按地区参考线路表现

结合访问地区与该地区的实际播放反馈排序，没有测量记录的线路仍需验证。

02

按需维护

服务器负责来源发现、更新和 AI 分类，客户端只为当前频道检查线路。

03

保留网络限制说明

中转不保证所有地区可用，中国大陆的下载与播放仍需当地网络实测。

05 / 使用场景

从桌面，到客厅。

Windows 与 macOS 提供简洁选台体验，并支持全屏观看与不同类型的媒体。

A

全屏与桌面画中画

全屏顶部左侧显示台名，中间显示当前和后两个节目，右侧提供返回与退出。画中画可悬浮置顶、拖动和调节音量；返回频道时继续播放。

B

纯音频电台

电台线路按音频媒体处理，不会因为缺少视频轨道就被误判为播放失败。

C

Mac AirPlay

同一网络中有兼容的 Mac AirPlay 接收端时，可将 Windows 播放器的音视频发送过去。
