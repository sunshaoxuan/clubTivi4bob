BOBTV / 简洁模式实际运行画面

01 / 播放

先预览，再切换频道。

点击频道开始静音预览，当前节目继续播放。预览准备好后再次点击即可切换，也可以双击直接切换。

01

节目时间轴

Windows 与 macOS 点击频道卡片可展开已匹配的当前节目和后续安排；暂无数据或加载失败时会显示相应状态。节目覆盖取决于已配置来源提供的数据。

02

收藏与音量

从菜单收藏频道，在播放器中调整音量。

03

全屏与桌面画中画

全屏顶部左侧显示台名，中间显示当前和后两个节目，右侧提供返回与退出。画中画可悬浮置顶、拖动、调整音量，并在返回频道时继续播放。

02 / 频道目录

按国家和地区浏览频道。

电视和电台按国家、地区与类型分类。CCTV-5 和 CCTV-5+ 保持独立。

01

频道排序

CCTV1 至 CCTV17 按数字排列，随后是 4K、8K 和 CGTN。

02

分类管理

可将国家和地区钉选到导航，修改分类和子分类。找不到的名称可直接输入创建，公开分类在后台同步并保留完整层级。右键可跨分类合并频道与去重线路。

03

电台

纯音频线路按电台处理，不会因缺少视频轨道被判定为播放失败。

03 / 公共目录

Windows 和 Mac 共用公共频道目录。

启动时先显示本机或随包目录，再在后台获取经过验证的公共频道清单。

01

公共记录

同步公共频道的增删、分类、合并、评分和线路淘汰记录，每分钟检查清单版本。分类区域显示当前分类的加载状态，全库记录数放在同步标记中。

02

离线修改

离线时保留修改，网络恢复后自动重试。频道列表会显示同步状态。

03

个人数据

收藏使用原设备指纹与专属密钥私有备份，仅可同步回原设备，不进入公共目录。观看历史和私人订阅保存在本机。

04 / 播放线路

线路中断时尝试切换。

线路排序参考实际播放情况。无法使用的线路也可以在频道菜单中淘汰。

01

区分频道

识别频道身份，避免将 CCTV-5 和 CCTV-5+ 等相近名称合并。

02

播放记录

成功解码会提升线路记录，播放失败和手动跳过会影响优先级。

03

替代线路

播放中断时尝试其他线路。候选线路无法播放时，返回原线路。

可用性取决于节目源和网络环境，部分频道可能无法播放。

05 / 服务器链路

来源发现与 AI 在服务器执行。

客户端从 BobTV 网站接收频道、分类和线路结果。安装包、节目单、台标及同步资源会比较主站与 cndrp 缓存节点速度，视频直连原始源。来源发现和 AI 在服务器执行。

01

地区排序

结合访问地区与该地区的实际播放反馈排序；没有测量记录的线路仍需验证。

02

按需维护

服务器负责发现、刷新与 AI 分类，客户端只为当前频道检查可用线路。

03

网络限制

缓存节点仅承接资源上传和下载，视频播放不经该节点。中国大陆的下载与节目源可用性仍需当地网络实测。

06 / 设备

电脑播放与 Mac AirPlay。

BobTV 支持 Windows 和 macOS。Windows 可向同一网络中的兼容 Mac AirPlay 接收端发送音视频。

01

Windows

可选 Setup 安装程序或 ZIP 便携包。

02

Mac

根据 Intel 或 Apple Silicon 芯片选择 DMG。

03

AirPlay

需要兼容的接收端，发送端和接收端需在同一局域网。

07 / TABLET

同一套界面，来到平板。

Android 与桌面共享简洁频道卡片和现代设置。小屏分区等宽、分类最多三行，卡片和节目单按空间缩放；视频保留原始比例，频道维护与 AI 仍由服务器负责。

01

触屏与退出

轻点预览，再点切换；长按打开频道菜单。Android 各页面保留“退出 BobTV”按钮，退出时停止播放和后台工作。

02

小屏也能完整预览

每级分类只占一行，更多选项从按钮上展开。至少保留一张预览卡片及节目单，特别矮的窗口进一步缩小卡片与文字。

03

原比例与更新

视频保持原始比例，平板缓存有上限。显示下载进度并检查完整性和签名后，由 Android 系统确认安装。

Android 实机播放、中国大陆网络速度与 Surface ARM64 实机测试仍需当地验证。Windows ARM64 原生包已通过交叉构建和架构校验。

08 / 设置

精巧有序的设置空间。

Windows 与 Mac 共用全新设置界面。七个分类整理频道、播放、同步、AI、备份和更新，原有功能与配置保留。

01

响应窗口大小

宽窗口使用侧栏，窄窗口自动折行并使用横向分类。

02

输入不会丢失

分类按需加载，切换后保留未保存的表单和滚动位置。

03

公共工具与更新

公共源审核、播放反馈和诊断摘要集中管理；自动更新显示独立状态。
