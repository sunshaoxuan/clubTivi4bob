隐私政策 / Privacy policy · 更新日期：2026-10-13

01 / CONNECTIONS

服务与网络连接

公共目录、分类、台标、节目单和更新信息来自 bobtv.briconbric.com。cndrp.com 可作为测速后选择的资源节点，视频直连原始信号源。

网络信息

网络接收方可见 IP、请求地址、连接时间和客户端提供的版本等信息。第三方节目源、投屏接收端和自行配置的服务有各自的数据处理规则。服务器负责来源发现与 AI，客户端不为此直接连接 GitHub。

应用专用指纹

设备指纹在本机生成，相关服务使用应用专用哈希识别本机。原始硬件序列号、MAC 地址和机器名不作为 API 身份字段发送，网络接收方仍可见建立连接所需的 IP。

02 / SYNC

公共目录与私人收藏分开

频道增删、分类、合并、线路转移、评分和淘汰记录用于公共维护。私人订阅地址、账号、观看历史和密钥不进入公共清单。

收藏只恢复到原设备

收藏备份使用原设备指纹、专属密钥和频道/线路标识，不包含私人订阅播放地址，也不分发给其他用户。服务保留备份供原设备恢复，关闭同步不会自动删除已有服务器备份或本机收藏。

在线备份控制

签名候选构建新增安装时的首次启用选项和“设置 → 同步与隐私 → 本机收藏在线备份”开关。关闭后不再开始备份读取或上传，已发出的请求无法撤回。现有正式版 1.1.2 的行为不因本文改变，这些控制将在包含它们的新正式版本中生效。

03 / DIAGNOSTICS

诊断分享默认关闭

分享播放状态和自动上传诊断摘要默认关闭，可在设置中分别控制。候选源提交需要另外确认分享权利和涉及的字段。

经过筛选的摘要

只允许时间、事件、来源标识、故障标记、运行时间、内存和平台等摘要字段。原始异常文本、路径和播放地址排除在摘要上传之外。服务器诊断摘要私有存放 14 天，不提供公开读取入口。

本机日志与转储

原始日志和转储保存在用户数据目录，不会作为摘要自动上传。转储可能含凭证或私人内存内容，分享前需检查。卸载程序保留用户数据。删除请求可联系维护者，勿在公开问题中发送凭证、设备标识或原始转储。

04 / ENGLISH

Privacy summary

BobTV uses its website and the cndrp resource relay for catalog/resource delivery. Video connects directly to the selected source. Network recipients see connection metadata such as IP and request path.

Public and private data

Public channel/category/route edits synchronize as shared records. Favorites use a separate device-private namespace, protected by an app-scoped hash and secret. Raw hardware identifiers and private subscription URLs are not sent as favorite backup fields. Disabling backup retains local favorites and does not erase a pre-existing server backup.

Controls and retention

Playback feedback and automatic diagnostic summaries are off by default. Filtered summaries are private and retained for 14 days; raw logs and dumps stay local. Signing candidates add an installer choice and a setting to disable private-favorite network backup. Current published 1.1.2 packages remain unchanged. Contact the maintainer for data handling requests; never post credentials or raw dumps in public issues.

DIAGNOSTICS V2

可选的 30 天脱敏诊断同步

仅适用于包含诊断同步 V2 的新客户端。首次启用需要明确同意，可随时在设置中关闭；旧摘要上传授权不会自动扩大。

范围和保存期限

允许上传最近 30 天仍可用的事件、应用版本、平台、请求阶段、节点、耗时、状态码和资源统计。每次使用有界批次增量同步，不上传原始异常、堆栈、播放地址、私人订阅、凭据、收藏、观看内容或转储。诊断使用应用内随机标识，不使用硬件序列号。主节点和中继最多保存到事件发生后 30 天，本机容量保护可能缩短可用历史。旧版摘要仍按原有 14 天政策保存。

中继和关闭

中国大陆经 cndrp 私有队列暂存，再由服务器任务使用 TLS 转交主节点。客户端区分中继暂存和主节点接收回执；主节点确认后中继删除内容，仅保留到期回执。未知网络也优先走中继。关闭后停止新的客户端上传并取消本机在途请求；已经到达服务器的请求不能撤回，按上述期限自动清理。服务器不提供公开诊断内容下载入口。

Optional 30-day diagnostic sync

New V2 clients require explicit opt-in, default to off and can be disabled at any time. A legacy opt-in does not authorize V2. Only allowlisted, redacted diagnostic events and network metrics are sent, with a random app-local identifier. No raw errors, stacks, media URLs, private subscriptions, credentials, favorites, viewing content or dumps are uploaded. Mainland-China uploads use the private cndrp queue and TLS forwarding to one origin. Receipts distinguish relay storage from origin acceptance. Both nodes expire data within 30 days of the event; bounded local storage may contain less history. Disabling stops new client uploads and cancels owned requests. Already received data expires under this policy. Legacy summaries retain their existing 14-day policy.
